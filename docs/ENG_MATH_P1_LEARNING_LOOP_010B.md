# ENG-MATH-P1-EXECUTION-010B 학습 결과·오답 재풀이·이어풀기 설계

## 1. 범위

- `[Confirmed]` 현재 영어·수학 학습기는 5문항 완료 뒤 정답 수와 문항별 `정답 / 다시 확인`을 표시한다.
- `[Confirmed]` 현재 결과 기록에는 선택한 답과 정답 값이 없고, 같은 5문항 전체 재풀기만 제공한다.
- `[Confirmed]` 새로고침하거나 브라우저를 닫으면 진행 중인 문항 번호와 앞선 결과가 사라진다.
- `[Adopted]` 이번 설계는 문항별 결과 강화, 오답만 다시 풀기, 같은 브라우저 이어풀기만 다룬다.
- `[Adopted]` 로그인, 서버 저장, 권한 DB, 결제, 분석 기록, 공개 데이터 변경은 포함하지 않는다.

## 2. 최소 성공 조건

1. `[Adopted]` 5문항 완료 화면에서 각 문항의 선택 답, 정답, 정오답을 확인할 수 있어야 한다.
2. `[Adopted]` 오답이 한 개 이상이면 `틀린 N문항 다시 풀기`가 표시되고, 오답만 원래 순서로 다시 출제되어야 한다.
3. `[Adopted]` 모두 맞힌 경우 오답 재풀이 버튼을 표시하지 않는다.
4. `[Adopted]` 진행 중 새로고침한 경우 `이어서 풀기`와 `처음부터 풀기` 중 하나를 선택할 수 있어야 한다.
5. `[Adopted]` 영어 풀이 제공과 수학 풀이 미제공 원칙을 바꾸지 않는다.
6. `[Adopted]` 잠금 문항의 직접 주소 차단과 무료 10문항 경계를 약화시키지 않는다.

## 3. 문항별 결과 구조

답을 제출할 때 현재 결과 객체를 다음 값으로 확장한다.

```json
{
  "questionId": "2026_csat_19",
  "label": "2026학년도 수능 · 19번",
  "selectedAnswer": 1,
  "correctAnswer": 1,
  "isCorrect": true
}
```

- `[Adopted]` 수학 단답형의 `selectedAnswer`와 `correctAnswer`는 앞뒤 공백을 제거한 문자열로 저장한다.
- `[Adopted]` 결과 목록은 `선택 ③ → 정답 ①`처럼 표시한다. 정답이면 `선택 ① · 정답`으로 짧게 표시한다.
- `[Adopted]` 지문, 선지 문구, 해설 전문은 진행 저장값에 넣지 않는다.

## 4. 오답만 다시 풀기

1. `[Adopted]` 완료 시 `isCorrect === false`인 `questionId`만 추린다.
2. `[Adopted]` 원래 묶음의 문항 순서를 유지한 채 오답 문항 배열을 만든다.
3. `[Adopted]` 결과 화면의 `같은 5문항 전체 다시 풀기` 위에 `틀린 N문항 다시 풀기`를 주 행동으로 표시한다.
4. `[Adopted]` 오답 재풀이에서는 진행 표시를 `오답 1 / N`으로 바꾼다.
5. `[Adopted]` 오답 재풀이 완료 뒤에는 재풀이 정답 수와 `문항 목록으로`만 표시한다. 다음 묶음 추천은 원래 5문항 결과에서만 제공한다.

## 5. 같은 브라우저 이어풀기

### 저장 위치

- `[Adopted]` 서버나 DB 없이 브라우저 `localStorage`를 사용한다.
- `[Adopted]` 저장 키는 `eng_math_session_v1:{subject}:{packId}`로 고정한다.
- `[Adopted]` 학생 이름, 이메일, 전화번호, 지문·선지·해설은 저장하지 않는다.

### 저장 값

```json
{
  "version": 1,
  "subject": "english",
  "packId": "english-2026-csat-19-23",
  "questionIds": [
    "2026_csat_19",
    "2026_csat_20",
    "2026_csat_21",
    "2026_csat_22",
    "2026_csat_23"
  ],
  "currentIndex": 2,
  "results": [],
  "updatedAt": "ISO-8601"
}
```

### 복구 규칙

1. `[Adopted]` 답 제출 직후와 다음 문제 이동 직후에 저장한다.
2. `[Adopted]` 저장된 `subject`, `packId`, `questionIds`가 현재 묶음과 모두 같을 때만 복구 후보로 인정한다.
3. `[Adopted]` 복구 후보가 있으면 자동 이동하지 않고 `이어서 풀기 / 처음부터 풀기`를 보여 준다.
4. `[Adopted]` `처음부터 풀기`를 고르면 해당 저장값만 삭제한다.
5. `[Adopted]` 5문항 결과 화면에 도달하면 진행 저장값을 삭제한다.
6. `[Adopted]` 문항 구성 변경, JSON 파싱 실패, 범위를 벗어난 문항 번호가 있으면 저장값을 사용하지 않고 삭제한다.

## 6. 화면 흐름

```text
문항 묶음 선택
  → 저장된 진행 없음: 1번 문항 시작
  → 저장된 진행 있음: 이어서 풀기 / 처음부터 풀기
  → 답 제출마다 결과 저장
  → 5문항 완료
  → 문항별 선택 답·정답·정오답
  → 오답 있음: 틀린 N문항 다시 풀기
  → 오답 없음: 다음 묶음 또는 문항 목록
```

## 7. 구현 시 최소 변경 범위

- `[Inference]` `src/EngMathPractice.jsx` 한 파일에서 현재 `LearningSession`, `SessionSummary`, `PracticeQuestion`의 상태 전달만 확장하면 구현할 수 있다.
- `[Adopted]` 새 컴포넌트 파일, 새 서버 함수, 새 DB 표, 새 패키지는 만들지 않는다.
- `[Adopted]` 구현 승인을 받기 전에는 코드를 수정하지 않는다.

## 8. 구현 뒤 검사 항목

1. `[Adopted]` 영어와 수학에서 일부러 두 문항을 틀리고 오답 두 문항만 다시 출제되는지 확인한다.
2. `[Adopted]` 전부 맞혔을 때 오답 재풀이 버튼이 없는지 확인한다.
3. `[Adopted]` 세 번째 문항에서 새로고침하고 앞선 두 결과와 현재 위치가 복구되는지 확인한다.
4. `[Adopted]` 다른 묶음의 저장값이 잘못 복구되지 않는지 확인한다.
5. `[Adopted]` 390px 화면에서 가로 넘침과 버튼 겹침이 없는지 확인한다.
6. `[Adopted]` 기존 무료 10문항만 브라우저에 전달되고 잠금 378문항의 본문·선지·정답이 전달되지 않는지 다시 검사한다.
