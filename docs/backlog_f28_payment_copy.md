## ⓐ 마스터 배지 문구가 사실과 다르다

**위치:** `src/Payment.jsx:327`

```jsx
🔧 검수용 — 테스트 키
```

**문제:** Production 은 이제 라이브 키(`live_ck_`/`live_sk_`)다. "테스트 키" 표기는
**거짓**이고, 마스터가 이 화면에서 결제하면 실제로 돈이 나간다. 배지를 믿고
테스트 결제를 하면 사고가 된다.

**수정안:** `🔧 검수 모드`

## ⓑ 결제창 상품명에 "구독"이 남아 있다

**위치:** `src/Payment.jsx:425`

```js
orderName: `짚이 ${plan.name} 구독 (1개월)`,
```

**문제:** F-2 에서 "월 구독" → "1개월 이용권"으로 정정한 취지와 어긋난다.
구현은 **자동 갱신되지 않는 단건 결제**인데, 결제창에 "구독"이 뜨면 학생·학부모가
자동 갱신으로 오해한다. 카드사 명세서에도 이 이름이 찍힌다.

**수정안:** `짚이 ${plan.name} 이용권 (1개월)`
→ 실제 노출: **`짚이 스탠다드 이용권 (1개월)`**

같은 화면의 `note` 는 이미 정합하다 — *"자동 갱신되지 않습니다. 만료 시 직접
재결제해 주세요."* (`src/Payment.jsx:73`)

## ⓒ /payment 하단 "순차 오픈 예정" 잔재

**위치:** `src/Payment.jsx:614`

```jsx
스탠다드·프리미엄 플랜은 결제 시스템 준비 완료 후 순차 오픈 예정입니다.
<br />
현재 무료 스타터 플랜으로 핵심 기능을 먼저 경험해보세요.
```

**문제:** 스탠다드는 **이미 열렸다**. 바로 위에서 결제 가능한 상품을 놓고
아래에서 "준비 완료 후 오픈 예정"이라고 말하는 모순이다.

**수정안:** 첫 문장 삭제. 프리미엄은 여전히 `available: false` 이므로 둘째 문장은
프리미엄만 가리키도록 다듬거나 그대로 둔다.

⚠️ **범위 주의:** `src/Payment.jsx:683`, `:694` 에도 "순차 오픈 예정"이 있으나
이것은 **학원 도입 상품의 기능 로드맵**(학생 리포트·관리 기능)이라 결제 오픈과
무관하다. **건드리지 않는다.**
