# 구간 표시 [A]~[F] 검증 대장 — 화면 원천 기준

> 생성: `node pipeline/bracket_ledger.mjs > docs/bracket_verification_ledger.md`
> **화면값**을 싣는다. 화면 원천은 `annotations.json`(all_data 를 덮어씀) ∪ `visual_marks.json` 이고,
> `getBracketInfo` 가 첫 매치에서 반환하므로 판정 단위는 **라벨**이다.
> all_data 의 `set.annotations` 값은 화면이 읽지 않는다 — 「all_data 잔재」 열로 격리했다.
> PDF 대조 여부는 자동 판정하지 않는다. `pipeline/bracket_ledger.mjs` 의 `VERIFIED` 에 손으로 적는다.
