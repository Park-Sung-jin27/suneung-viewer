# 본문↔pat 불일치 6건 — 선지 대조 판정 의견 (발주 D-85 · 2026-08-21)

> **판정이 아니라 의견이다.** 확정은 심사관·대표 몫이다.
> 6건 모두 D-85 정리에서 **제외**했다. 데이터는 손대지 않았다.

## 1. 2025수능 `r2025b` Q6 선지1 — **pat(R1) 채택 의견**

- **발문**: (나)의 '천두슈'와 '장쥔마이'가 모두 동의할 수 있는 진술로 가장 적절한 것은?
- **선지**: 전통 사상은 과학 및 과학 정신과 양립할 수 없는 관계에 놓여 있다.
- **해설 요지**: 장쥔마이는 인생관과 과학을 별개 영역으로 보아 공존을 인정했다.

**의견** — 지문에 장쥔마이의 입장이 **명시되어 있고**, 선지는 그것을 반대로 서술했다.
없는 말을 지어낸 것(R3)이 아니라 **있는 사실을 뒤집은 것(R1)** 이다.
본문 코드 R3 은 부적절하다.

## 2. 2025수능 `r2025c` Q11 선지3 — **보류**

- **선지**: 노이즈 예측기는 확산 이미지를 입력받아 노이즈를 예측하여 출력한다.
- **해설 요지**: '특성 추출 → 잠재 표현' 이라는 **중간 단계를 누락**했다.

**의견** — 해설이 스스로 「누락」이라고 쓴다. **누락은 R4(여러 곳을 잘못 이어 붙임)도, R1(사실을 바꿔치기)도 아니다.**
둘 중 하나를 고르는 문제가 아니라 **코드 체계에 「생략·불완전 서술」 축이 없는 문제**로 보인다.
→ 심사관 판단 필요. 지금 어느 쪽으로도 덮어쓰지 말 것.

## 3. 2025수능 `r2025c` Q11 선지4 — **본문(R2) 채택 의견**

- **선지**: 노이즈 예측기를 학습시킬 때는 예측된 노이즈가 정답으로 사용된다.
- **해설 요지**: 정답 = 생성기의 노이즈, 출력 = 예측된 노이즈. **선지가 둘의 역할을 뒤바꿨다.**

**의견** — 「정답 ↔ 출력」 역할 전도. **관계 뒤집기(R2)가 정확하다.** pat 의 R1 은 기본값 오채움으로 보인다.

## 4. 2025수능 `r2025c` Q11 선지5 — **본문(R2) 채택 의견**

- **선지**: 역확산 과정에서 단계가 반복될수록 확산 이미지는 원본과의 유사성이 줄어든다.
- **해설 요지**: 지문은 「원본에 가까워진다」. 선지는 **방향을 정반대로** 뒤집었다.

**의견** — 방향 전도. **R2 가 정확하다.**

## 5. 2025수능 `r2025d` Q15 선지5 — **본문(R3) 채택 의견**

- **선지**: ㉠과 ㉡은 모두, 인터넷 ID마다 개인의 자기 정체성이 다르다고 보겠군.
- **해설 요지**: 「지문 어디에도 그런 주장은 없다」.

**의견** — 해설이 명시적으로 「없는 주장을 만들어냈다」고 쓴다. **지문에 없는 말(R3)이 정확하다.**

## 6. 2022수능 `l2022b` Q25 선지5 — **본문(L1,L2) 채택 의견**

- **선지**: 닭장차에 끌려가게 된 김달채는 건물 모퉁이에서 들려오는 함성에 안도감을 느낀다.
- **해설 요지**: 「'닭장차에 끌려갔다'는 **사실**과 '안도감을 느낀다'는 **정서** 모두 지문과 다르다」.

**의견** — 해설이 **두 축을 명시**한다. 정서 오독은 **L2** 축인데 `pat` 에는 L1 만 있다.
**본문의 두 코드(L1, L2)가 더 정확하다.** 다만 사실 오류 쪽이 L1(표현·형식 오독)에 정확히 들어맞는지는
별도 확인이 필요하다 — L4(구조·맥락 오류)일 여지가 있다.

## 남는 문제

- **`pat` 의 R1 쏠림** — 5건 중 4건이 `pat=R1` 인데 실제 유형은 R2·R3 로 갈렸다.
  `pat` 이 기본값 R1 로 채워졌을 가능성이 있다. 이번 6건 밖에도 같은 현상이 있는지는 **미조사**다.
- **코드 체계의 빈 축** — 2번 사례처럼 「생략·불완전 서술」을 담을 코드가 없다.
