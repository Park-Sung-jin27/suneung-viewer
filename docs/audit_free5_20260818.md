### 1. 2026수능 `l2026a` Q21 — `<보기>` 후반 절단 + 원문에 없는 문구로 봉합

```
원문 : …청중의 현실 속 다양한 요소를 중첩하는 방식으로 이야기의 변모가
       이루어졌어요. 이로써 부정적 면모를 지닌 다양한 인간에 대한 비판을
       드러내거나, 현실감을 부여하여 인물이 처한 상황을 …
데이터: …청중의 현실 속 다양한 요소를 중첩하는 방식을 사용합니다.
```
`<보기>` 가 60자에서 끊기고, **원문에 없는 「을 사용합니다.」로 문장을 닫았다.**
선지가 요구하는 「이야기의 변모」·「비판」·「현실감」 정보가 통째로 없다.

### 2. 2026수능 `l2026c` Q30 — `<보기>` 내용이 다른 문구로 대체

```
원문 : …자신의 생각이나 경험을 일반화하거나, 주어진 상황을 주관화하거나,
       상대의 생각을 헤아리는 모습을 보여준다. 이는 인물의 생각을 타당한
       것처럼 보이게 하지만 한편 …
데이터: …자신의 생각이나 경험을 투영하여 현실을 주관화하거나 왜곡하는
       양상이 나타난다.
```
원문이 제시한 **세 가지 양상(일반화 / 주관화 / 헤아리기)** 이 사라지고
원문에 없는 서술로 바뀌었다. 선지가 이 세 양상에 대응할 경우 판단 근거가 없다.

| 선지 | 원문 | 데이터 |
