## 2014수능 A·B 원본 재소싱 — 텍스트층 없음 확정

발주 「D-130 추가」로 외부 출처에서 다시 받아 **텍스트층 유무만** 검사했다.
OCR 은 착수하지 않았다(§13⑬ · 별도 절차 승인 사항).

같은 **머리말·꼬리말**이고 본문은 이미지다.

### 결정적 비교 — 사이트 문제가 아니라 원본 문제다

이미 보유한 `_done/` 판본으로 같은 시기를 나란히 재 보면 갈라지는 지점이 분명하다.

| 회차 | 앞 6면 추출 글자 | |
|---|--:|---|
| 2014_6월A / 6월B | 11,024 / 11,926 | ✅ |
| 2014_9월A / 9월B | 13,167 / 11,823 | ✅ |
| **2014수능A / 수능B** | **211 / 193** | 🔴 |
| 2015수능A / 수능B | 12,633 / 13,743 | ✅ |
| 2016수능A / 수능B | 13,544 / 13,354 | ✅ |

**2014수능 두 회차만 스캔이다.** 같은 해 6·9월도, 앞뒤 연도 수능도 전부 텍스트층이 있다.
서로 독립된 세 출처(로컬 `_done` · SBS 아카이브 · legendstudy)가 모두 스캔본이므로,
특정 사이트의 재가공 문제가 아니라 **2014학년도 수능 문제지가 애초에 스캔으로 배포된 것**으로 본다 `[Inference]`.

### 미확인

한국교육과정평가원 공식 자료실(`suneung.re.kr` 기출 게시판)은 목록이 스크립트로 그려져
`curl` 로 2014학년도 게시물을 짚지 못했다. **평가원 원본 직접 확인은 남아 있다** `[확인 필요]`.
다만 위 세 출처가 평가원 배포본에서 갈라져 나온 것이라 결과가 같을 가능성이 높다.
