## ⓑ 선지별 재작성안

`cs_ids` 는 다섯 선지 모두 적절하다 — 손대지 않는다.

### #1 `ok:true` · cs_ids `[s17]` — 표기 교체로 충분

현재: `… 가는 을의 데이터를 재사용할 수 있게 된 기업이므로 이에 해당한다.`

`가` = ㉮, `을` = ㉯ 다(선지 원문 「㉮는 … ㉯의 데이터를 재사용할 수 있게 되었으므로」와 글자 그대로 대응).
「을」은 `bogi` 에도 없는 글자로, 오치환의 잔재다.

> **안**: `… ㉮는 ㉯의 데이터를 재사용할 수 있게 된 기업이므로 이에 해당한다.`

논지 불변. 근거 s17(생성 비용은 전송받은 데이터를 복제·재사용하면 절감).

### #2 `ok:true` · cs_ids `[s18, s19]` — 표기 교체로 충분

현재: `… 다(제3자)가 분쟁 없이 데이터를 전송받으면 …`

선지 원문이 「전송받는 제3자가 ㉰라면」이므로 `다` = ㉰ 다.

> **안**: `… ㉰(제3자)가 분쟁 없이 데이터를 전송받으면 …`

논지 불변.

### #3 `ok:true` · cs_ids `[s22, s23]` — 표기 교체로 충분 (대응이 뒤집힘에 주의)

현재: `… 라(신규 기업)가 거래에 실패해 데이터 생성 비용이 발생하면 …`

선지 원문은 「㉰가 ㉱와의 거래에 실패해 … ㉰에 데이터 생성 비용이 발생하면」이다.
신규 기업은 본문 s22 에서 **㉰** 다. 즉 여기서는 `라` = **㉰** 이며, #4 의 `라`(=㉱)와 다르다.

> **안**: `… ㉰(신규 기업)가 ㉱와의 거래에 실패해 데이터 생성 비용이 발생하면 …`

논지 불변.

### #4 `ok:true` · cs_ids `[s21]` — 🔴 **논지 재작성** (표기 교체로 해결되지 않음)

선지: `[A]와 달리 [B]의 입장에서, 정보 주체의 데이터가 ㉯에서 ㉱로 이동하여 집적·처리될수록 기업 간 공유나 유통이 위축될 수 있다고 보겠군.`

현재 해설은 **선지를 반박한다** — `선지는 데이터가 '다에서 라로 이동하여 집적·처리'된다고 했는데, 이는 데이터 이동 방향을 반대로 서술한 것이다` — 그래 놓고 결론은 `✅ 지문과 일치하는 적절한 진술` 이다. 본문과 결론이 서로 어긋난다.

반박 쪽이 오독이다. s21 은 「정보 주체가 … 기업으로 데이터를 이동하면, 데이터가 집중되어 데이터의 공유나 유통이 위축될 수 있다」이고, 데이터를 내주는 쪽이 ㉯, 데이터가 모이는 쪽이 ㉱ 다. 선지의 방향이 지문과 같다.

> **안**:
> `📌 지문 근거: "정보 주체가 보안의 신뢰성이 높고 데이터 제공에 따른 혜택이 많은 기업으로 데이터를 이동하면, 데이터가 집중되어 데이터의 공유나 유통이 위축될 수 있다는 우려도 있다."`
> `🔍 [B]는 데이터 집중을 우려한다. 정보 주체의 데이터가 ㉯(데이터를 보유했던 기업)에서 ㉱(데이터가 집중된 기존 기업)로 옮겨 가 쌓일수록 공유·유통이 위축된다는 것이 s21 의 내용이다. 선지의 이동 방향은 지문과 같다. [A]는 같은 이동을 두고 공유·유통이 촉진된다고 보므로(s20), 「[A]와 달리 [B]의 입장에서」라는 단서도 맞다.`
> `✅ 지문과 일치하는 적절한 진술`

### #5 `ok:false` · cs_ids `[s21, s20]` · pat `R1` — 🔴 **논지 재작성** (정답 선지)

선지: `[B]와 달리 [A]의 입장에서, ㉯는 ㉮로 데이터를 이동하여 경제적 이득을 취할 수 있으므로 데이터의 공유나 유통의 활성화에 기여할 수 있다고 보겠군.`

현재 해설은 `정보 주체가 데이터를 이동하여 경제적 이득을 취하는 행위(나)는 … 활성화에 기여한다고 본다` 라고 **선지를 지지하는 서술만 해 놓고** 결론만 `❌` 다. 왜 틀렸는지가 없다.

틀린 이유는 **주체**다. 데이터를 이동시키는 것은 정보 주체이지 ㉯(데이터를 보유했던 기업)가 아니다.
s21 은 「**정보 주체가** … 데이터를 이동하면」이고, s19 에서 ㉯는 데이터를 내주는 쪽이다.
㉯가 스스로 데이터를 옮겨 경제적 이득을 취한다는 진술은 지문에 없다.

> **안**:
> `📌 지문 근거: "그런데 데이터 이동권의 법제화로, ㉮정보 주체가 지정하여 데이터를 전송받게 된 기업은 ㉯정보 주체의 데이터를 보유했던 기업으로부터 데이터를 받으면 비용을 절감할 수 있다."`
> `📌 지문 근거: "이에 따라 기업 간 공유나 유통이 촉진되고, 관련 산업이 활성화된다."`
> `🔍 데이터를 이동시키는 주체는 정보 주체다(s21 「정보 주체가 … 데이터를 이동하면」). ㉯는 데이터를 내주는 쪽이지, 스스로 데이터를 옮겨 경제적 이득을 취하는 쪽이 아니다. 공유·유통이 활성화된다는 s20 의 진술은 맞지만, 그 주체를 ㉯로 바꿔 놓은 것이 이 선지의 잘못이다.`
> `❌ 지문과 어긋나는 부적절한 진술 [사실 왜곡]`

`pat` 은 현행 R1 `[사실 왜곡]` 을 유지한다 — 주체를 바꿔 놓은 것이 사실 왜곡에 해당한다.
