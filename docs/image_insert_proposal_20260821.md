## 삽입 위치 — `sents` 가 아니라 `bogiImage`

발주는 `sentType:"image"` sent 삽입을 전제했으나, **둘 다 지문 그림이 아니라 문항의 `<보기>` 자료**다.
기존 스키마에 이미 그 자리가 있다:

```json
"bogiImage": { "url": "/images/2026_s3_q12_bogi.png", "alt": "집게 A, B 장치 그림" }
```
(2026수능 `r2026c` Q12 · 2025수능 `r2025c` Q13 은 `bogiImages` 배열)

### 제안 1 — `2019수능 :: r2019d :: Q27`

**현재** — `bogi` 에 한 줄만 있고 **표 전체가 없다.**
```
"bogi": "○읽기 계획: 1문단을 훑어보면서 뒷부분을 예측하고 질문 만들기를 한 후, 글을 읽고 점검하기"
```
원본에는 이 줄 아래에 「예측 및 질문 내용 / 점검 결과」 5행 표가 있고, **선지 ①~⑤ 가 그 표 안에 박혀 있다.**
지금 화면에서는 학생이 ①~⑤ 가 무엇을 가리키는지 알 수 없다.

**제안** — `bogi` 는 그대로 두고 아래를 추가한다.
```json
"bogiImage": {
  "url": "/images/2019_r2019d_q27_bogi.png",
  "alt": "학생의 독서 기록 표 — 예측 및 질문 내용 5개와 그에 대한 점검 결과 ①~⑤"
}
```

### 제안 2 — `2019수능 :: r2019d :: Q31`

**현재** — `bogi` 516자로 (1)(2) 설명은 다 있다. **동심원 그림만 없다.**
발문이 「`<보기>`를 참고할 때, [A]에 대한 이해로…」이고, `<보기>` 오른쪽에 점 P·O 와
구 껍질을 그린 그림이 함께 실려 있다. 텍스트만으로는 P 와 O 의 위치 관계가 보이지 않는다.

**제안**
```json
"bogiImage": {
  "url": "/images/2019_r2019d_q31_bogi.png",
  "alt": "구 껍질을 이루는 부피 요소와 구 외부의 점 P, 구의 중심 O 를 나타낸 동심원 그림"
}
```

## 병합 전 확인할 것

1. **프론트가 `bogiImage` 를 그리는지** — `r2026c` Q12 가 화면에 나오는지 보면 확인된다. 그리지 않으면 파일만 늘고 화면은 그대로다.
2. 두 PNG 를 육안으로 확인 (이 문서와 함께 제출).
3. 병합은 `all_data_204.json` 수정이므로 D-85 와 같은 3중 잠금(백업 → 계수 대조 → 게이트 비교)을 건다.

## 남은 위험

- `alt` 문구는 제가 그림을 보고 쓴 것이다. **원본에 적힌 설명이 아니다.** 화면에는 안 보이지만
  화면 낭독기가 읽는 값이라, 표현이 마음에 안 들면 병합 전에 고쳐야 한다.
- Q27 은 **선지가 그림 안에 있다.** 이미지를 넣어도 선지 텍스트(`choices[].t`)와 그림 속 ①~⑤ 가
  중복돼 보일 수 있다. 화면에서 어떻게 보이는지 확인이 필요하다.
