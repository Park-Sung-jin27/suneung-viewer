## 1. 현 구조 진단 (표본 기반)

**잘 되어 있는 것 [Confirmed]**

- 3단 골격(🔍 분해 → 📌 verbatim 근거 → ❌ 대조 결론)이 논리적으로 완결. 형광펜(cs_ids)과 근거 인용이 1:1.
- "선지는 X, 지문은 Y" 대조 구문이 오독 지점을 정확히 짚음.

**3~4등급 학생 관점의 공백 5가지 [Inference — 표본 4건 공통]**

1. **결론이 맨 끝에만 있다**: 학생은 첫 줄에서 "맞는지/틀린지+왜"의 방향을 잡아야 끝까지 읽는다. 지금은 433자를 다 읽어야 결론에 도달.
2. **"왜 내가 이 선지에 끌렸는가"가 없다**: 오답 선지는 설계된 함정인데, 함정의 설계 원리(지문의 실제 표현을 재활용해 그럴듯하게 만든 지점)를 짚어주지 않으면 학생은 "아 그렇구나" 하고 같은 함정에 또 걸린다.
3. **근거 문장 자체가 어렵다**: 📌 인용문("…다양한 시각을 표면화하였다")을 3~4등급은 그 문장부터 못 읽는다. 대표 모델은 `→` 뒤에 풀이를 붙이는 관행이 있으나 규격이 아니라 들쭉날쭉.
4. **시험장 전이(transfer)가 없다**: "이 문제는 이렇게 틀렸다"에서 끝나고, "다음에 같은 패턴을 어떻게 알아채는가"라는 행동 지침이 없다.
5. **pat 코드가 학생에게 무의미**: "관계 전환(R2)"는 운영자 언어. 학생 언어 명명이 없어 패턴 학습(본 제품의 moat)이 학생에게 축적되지 않는다.

## 2. v2 구조 설계

### 2-A. 오답 선지 (ok:false) — 6블록

```
🎯 한눈 요약: 선지는 "A"라 했지만, 지문은 "B"다.          ← 신규 (1문장, 40자 내)
🔍 선지 분해
· (조각별 분해 — v1 그대로, 모든 핵심 주장 조각 빠짐없이)
📌 지문 대조
· "지문 verbatim 인용"
  → 쉬운 말: (그 문장이 무슨 뜻인지 한 문장)                ← 규격화 (인용마다 의무)
· (선지가 맞게 짚은 부분 인정 + 지문이 실제로 말하는 바 — v1 그대로)
⚡ 함정 포인트: (이 선지가 그럴듯해 보이는 이유 1~2문장)      ← 신규
🧠 다음엔 이렇게: (같은 패턴을 알아채는 행동 지침 1문장)       ← 신규
❌ (결론 1문장) — 패턴명: 관계 뒤집기(R2)                    ← v1 유지 (마지막 줄, 게이트 ⑤)
```

### 2-B. 정답 선지 (ok:true) — 5블록

```
🎯 한눈 요약: 지문의 "B" 그대로다.                          ← 신규
🧭 찾는 길: 발문/선지의 핵심어 → 지문 어디를 봐야 하는지 1문장  ← 신규 (탐색 전략)
📌 지문 근거: "verbatim 인용"
  → 쉬운 말: (뜻풀이 — v1의 2단을 규격 표기로)
🔗 연결: 그래서 선지가 옳은 이유 (v1의 3단)
✅ (결론 1문장)                                            ← v1 유지
```

### 2-C. 보기(<보기>) 문항 — v1 "3단 대조 변주" 유지 + 🎯/⚡/🧠 동일 추가

(보기 이중 점검 원칙 그대로: 보기상 맞는 부분 인정 → 선지가 적절하려면 작품에 무엇이 있어야 하나 → 작품 실제)

- 신규 3블록 합계 **+3문장 이내** (🎯 1 / ⚡ 1~~2 / 🧠 1). 코어 3단은 v1 분량 가이드(3~~6문장) 유지.

## 3. 호환성 체크리스트 (이 설계가 깨뜨리지 않는 것)

1. **결론줄=ok 게이트(§13⑤)**: ✅/❌ 결론은 여전히 **마지막 줄**. 🎯는 이모지가 달라 게이트 오탐 없음 (✅/❌ 문자를 🎯 줄에 쓰지 말 것).
2. **📌 verbatim exact(§13⑥, C_anchor)**: "→ 쉬운 말" 풀이는 인용 **밖** 별도 행 — 인용문 자체는 한 글자도 변형 금지.
3. **선지 자립(§7)**: 🎯·⚡·🧠 어디서도 타 선지 언급 금지 ("②보다 ⑤가…" 금지).
4. **근거 완전성(rubric 횡단 원칙)**: ⚡·🧠이 새로운 지문 문장을 근거로 쓰면 그 문장도 📌 인용 + cs_ids 형광펜에 추가.
5. **W_struct_missing 게이트**: 전환기에는 v1 3단만 검사 유지. v2 전면 적용 후 🎯 부재를 WARNING에 추가 (단계적).

## 4-A. v1 → v2 변환 예시 — 오답형 (대표 모델 r20276b Q5②, R2) **[Adopted 2026-07-08 대표 승인]**

```
🎯 한눈 요약: 선지는 ㉠이 '노비의 인식'을 담았다고 했지만, 지문은 '양반의 시각'을 담았다고 말한다.

🔍 선지 분해
· '노비와 양인의 신분 격차가 줄어들면서' → 사회적 배경
· '노비들이 갖게 된 인식' → 인식의 주체를 '노비'로 봄
· '형상화하였다' → ㉠(양반들의 글)이 그 인식을 표현했다는 주장

📌 지문 대조
· "여러 사정으로 양인과 노비의 신분 격차도 줄어들었다."
  → 쉬운 말: 신분 차이가 줄었다는 배경 자체는 지문에 있는 사실이다.
· "양반들은 노비의 죽음을 애도하거나 행적을 기록한 여러 글을 통해 노비에 대한 다양한 시각을 표면화하였다."
  → 쉬운 말: 그 글(㉠)에 담긴 것은 '양반이 노비를 어떻게 봤는가'이지, '노비가 무엇을 느꼈는가'가 아니다.

⚡ 함정 포인트: 앞부분(신분 격차 축소)이 지문 그대로라 뒷부분까지 맞는 것처럼 보이게 설계된 선지다. 사실인 배경 뒤에 주체를 슬쩍 바꿔 끼웠다.

🧠 다음엔 이렇게: '누가 가진 인식/시각'인지 주체에 동그라미를 치고 지문의 주어와 맞춰 보자.

❌ 인식의 주체를 노비↔양반으로 뒤바꾼 선지 — 패턴: 관계 뒤집기(R2)
```

```
🔗 연결: 선지는 바로 이 '과정을 설명하지 않는다'는 빈틈을 지적한다. 지문이 직접 인정한 한계를 짚었으므로 비판으로 가장 적절하다.

✅ 단순 관점의 한계를 정확히 지적한 적절한 비판
```

## 4-C. v1 → v2 변환 예시 — 보기형 (대표 모델 l2026a Q21②, L3) **[Adopted 2026-07-08 대표 승인]**

```
🧠 다음엔 이렇게: '위선·비판·성찰' 같은 큰 단어가 선지에 보이면, 인물이 정말 겉과 속이 다르게 행동한 장면이 있는지부터 확인하자.

❌ 작품에 없는 '위선'이라는 의미를 부여한 선지 — 패턴: 의미 부풀리기(L3)
```
