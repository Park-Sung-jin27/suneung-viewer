## 자체 발견 — 진단 도구 오탐 2건

`pipeline/release_diag.mjs` 를 새로 만들면서 두 번 틀렸고, 둘 다 고쳤다.

1. **④ 구간표시** — 처음에는 `annotations.json` 전체를 문자열로 훑어 라벨 글자만 찾았다.

   → `bracket` 과 `blank-box` 를 그 세트의 항목 안에서 정확히 찾도록 고쳤다.
2. **⑤ 글자손상** — PUA·ZWSP 정규식을 리터럴 문자로 적었더니 파일에 쓰는 과정에서 글자가 죽어
   `/[-]/` 같은 빈 검사로 변했다. → `-` 처럼 코드포인트로 적고, 자가검증했다.

**이 도구의 판정은 후보까지다.** ④·⑨·⑩·⑪ 은 원본 지면 대조로만 확정한다.
