# 문항 영역 붙임 — 규칙으로 판별 불가 (2026-08-25, 발주 D-101 ③)

> 발문·선지·보기의 줄바꿈 자리 1,117곳 중, 안전 규칙으로 확정되지 않아
> **손대지 않은** 자리다.

## 원인 (규명 완료)

1차 판별(`newline_fix`)은 「PDF 줄 끝에 공백이 없으면 어절 중간 절단」으로 단정했다.
그런데 PyMuPDF 가 이 PDF 를 **줄마다 별도 블록**으로 쪼갠다(2016_6월B 기준 96.1%).
블록 마지막 줄은 렌더 텍스트가 공백으로 끝나지 않으므로, **어절 경계에서도
`sp=false`** 가 나온다. 발문이 여기 걸렸다.

```
PDF: '36. 다음 <학습 활동 과제>를 해결한 내용으로 적절하지 않은'   ← 블록 끝, 공백 없음
     '것은? [3점]'                                            ← 다른 블록
데이터: "…적절하지 않은것은? [3점]"                              ← 붙임으로 오판
```

기하(남은 여백 vs 다음 글자 폭)도 근거가 못 된다. 양쪽 정렬이라 **모든 줄이 우측
경계에 닿아** gap 이 3~4pt 로 같다 — 공백이어야 할 자리도, 붙임이어야 할 자리도.

→ PDF 에서 얻을 수 있는 신뢰 가능한 근거는 하나뿐이다:
**줄 끝에 공백이 있으면 어절 경계**(반대는 성립하지 않는다).

## 적용한 규칙 (오탐 0 확인분만)

| 순서 | 규칙 | 판정 |
|---|---|---|
| ① | 뒤 조각이 조사·어미로 시작 | 붙임 |
| ② | 뒤 조각이 의존명사(것은·때문·수 있…)로 시작 | 공백 |
| ③ | 앞 조각이 오탐 없는 조사(를·의·에서·으로…)로 끝남 | 공백 |
| ④ | 앞 **어절**(3글자 이상)이 관형형(~한/된/는/운/던) | 공백 |

### 폐기한 규칙과 그 이유

**「앞 조각이 조사·어미로 끝남 → 공백」** — 1글자 어미(다·고·는·은·이)가 명사 끝
음절과 겹쳐 오탐이 쏟아졌다.

```
아름다|움을   → "아름다 움을"   🔴   (「다」를 어미로 오인)
과|제는      → "과 제는"       🔴   (「과」를 조사로 오인)
지|연되어    → "지 연되어"     🔴
서서|히      → "서서 히"       🔴
완|수한다    → "완 수한다"     🔴   (「수」를 의존명사로 오인)
주인|공의    → "주인 공의"     🔴   (「인」을 관형형으로 오인)
```

이래서 `과`·`와`·`께`·`인`을 목록에서 뺐고, 1글자 의존명사는 조사가 붙은
형태(`수 있`·`수가`·`바가`)로만 인정한다.

## 판별 불가 254건의 성격 `[Inference]`

표본 12건 육안 확인 결과 **10건은 어절 중간 절단(붙임이 맞음)**, 2건은 띄어야 했다.

```
이동▸하고     → 이동하고      ✅ 붙임이 맞다
혼란스▸러운   → 혼란스러운    ✅
드러▸내고     → 드러내고      ✅
모티▸프는     → 모티프는      ✅
아름다▸움을   → 아름다움을    ✅
규범▸적인     → 규범적인      ✅
복잡한▸심정   → 복잡한 심정   🔴 띄어야 한다 (④ 규칙으로 이후 교정됨)
현실▸인식     → 현실 인식     🔴 띄어야 한다 (명사+명사, 규칙 밖)
```

남은 오류는 **명사+명사** 자리로 추정된다(합성어인지 두 어절인지 규칙으로 못 가른다).
전수 판정에는 형태소 분석기나 사람의 육안 검수가 필요하다. `[확인 필요]`
