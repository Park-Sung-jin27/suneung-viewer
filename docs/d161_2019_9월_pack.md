## ① 재분할 방식 상신 — 적용 안 함

### 방식: S-11 의 **문장 경계 규칙만** 빌려 쓰고 `resplitProse` 는 쓰지 않습니다

발주대로 `resplitProse` 는 호출하지 않았습니다. 그 함수는 **줄을 이어 붙인 뒤 자르고 id 를
s1 부터 다시 매기기** 때문에, 이 세트에 쓰면 기존 id 가 통째로 바뀌어 `cs_ids` 14곳이 전부 끊깁니다.

대신 **경계 판정 규칙만** 씁니다.

1. `body` 문장 안에서만 자른다 (`omission`·`author` 는 손대지 않는다)
2. 자르는 자리 = **종결어미 + 종결부호 + 공백**
3. **인용부호 안에서는 자르지 않는다** (여닫이 깊이 추적)
4. **기존 id 는 그대로 두고**, 쪼개진 뒤쪽 조각만 새 id(`s9NN`)로 배열 제자리에 끼운다
   → `cs_ids` 가 가리키던 문장은 **첫 조각으로 남아** 끊기지 않는다

### 🔴 그래도 남는 문제 — 「첫 조각으로 남긴다」는 정확한 정박이 아닙니다

`cs_ids` 가 끊기지는 않지만, **원래 그 선지가 가리키던 대목이 첫 조각에 있다는 보장이 없습니다.**
예를 들어 Q43#5 `[s8]` 의 근거가 `s8` 의 세 번째 문장에 있다면, 재분할 후에도 첫 조각을
가리켜 **형광펜이 엉뚱한 문장에 켜집니다.** 검산으로는 못 잡습니다(문장이 실재하므로 통과).

**따라서 재분할과 14곳 재정박은 한 묶음이어야 합니다.**
원본 대조 팩에 **14개 선지의 근거 어구**를 함께 주시면 기계 대조가 가능합니다.
