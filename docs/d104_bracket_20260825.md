기존 bracket 4개가 **(가) 유치환 「채전」의 시행**(`l2023ds9~12`)을 가리키고 있었다.

```

```


시행 앞에 붙어 있어서). bracket 정박은 끝났으므로 화면 표시는 정상화되지만,
본문에 `[A] `·`[C] ` 접두가 남아 시행이 원문과 다르게 보입니다. 별건으로 남깁니다.
