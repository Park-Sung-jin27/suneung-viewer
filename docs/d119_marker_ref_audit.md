## 읽는 법 — ①만 실질적이다

**① 고아 7세트(LIVE 5)가 진짜 점검 대상**이다. r20249b Q5 사고가 이 신호로 드러났다.
다만 고아라고 전부 결함은 아니다 — r20249d 의 `ⓐ` 는 원본 발문이 「17. ⓐ와 문맥상…」인데
데이터가 「굳어졌다와 문맥상…」으로 **단어를 직접 인용**한 경우다. 의미 손실이 없어 기능상
문제가 아니다. **원본 지면 대조 없이는 가릴 수 없다.**

**② 역고아 82세트는 오탐이 많다.** 문항의 `<보기>` 안에서 새로 정의한 원문자, 해설이
설명을 위해 붙인 기호 등이 섞인다. 본문에 없는 것이 정상인 경우가 대부분이다.

**③ 오치환 후보 7건은 전수 오탐이다.** 탐지 규칙이 「X~Y」 꼴을 찾는데,
  · `ㄱ~ㄹ에 대해` · `ㄱ~ㅁ에 대해` — `<보기>` 안 항목 표기(ㄱㄴㄷㄹ)이지 원문자가 아니다
  · `Ⓐ~Ⓔ 중` — 다른 계열 원문자(U+24B6~)로, 이 도구의 마커 집합 밖이다
  · `"~에 의` · `면 ~ 않을` · `와 ～P 중` — 물결표가 범위 표기가 아닌 자리다
  규칙을 다듬기 전에는 ③ 수치를 판정 근거로 쓰지 않는다.
