```
이적에 원수가 여러 날 만에 연주에 도달하여 군마를 다 쉬게 하고 원수도 노곤하여 사관에서
```

166자 안에 **종결부호가 끝의 `.` 하나뿐**이다. 쉼표로 이어지는 고전소설 장문이라
`resplitProse`(종결어미 + 종결부호 기준)로는 자를 자리가 없다.
**나누려면 손으로 경계를 정해야 하고, 그건 문장 분할 규약 밖이다.**

### 제안 — 나누지 않는 길이 있다 `[Inference]`

`[A]` 가 **`s2` 전체를 포함**한다면 분리가 필요 없다. `s2` 는 「사관에서 쉬다 → 나비를 따라
→ 별세계에 이름」으로, **꿈의 시작 전체**를 담고 있어 `[A]` 의 자연스러운 시작점이다.

- `[A]` = `s2`~`s11`(남가일몽에서 깸)이면 **분리 없이 정박 가능**하다.
- 원본에서 꺾쇠가 `s2` **중간**부터 시작한다면 그때만 분리가 필요하다.

**심사관 화면 실측 요청**: 원본에서 `[A]` 꺾쇠가 「이적에 원수가」부터 시작하는지,
