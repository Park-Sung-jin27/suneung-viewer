## 읽는 법

- **영역** — `독서·문학`은 서비스 대상, `화작·문법`은 대상 밖이다. 원본 문항 번호로 쪽 경계를 잡았다.
  (2022학년도~ 공통 1~34 뒤부터 선택과목 / ~2021학년도 화작문 1~15 뒤부터 독서·문학)
- **분류** — `자료`=지문·문항 자료 후보, `장식`=테두리·틀·표지 글자처럼 내용이 없는 것.
- **병합** — 같은 그림이 여러 객체로 쪼개져 있다. 같은 병합 번호끼리 합치면 그림 1개다.
- 벡터 그림은 여기 없다(래스터 이미지 객체만 추출된다).
