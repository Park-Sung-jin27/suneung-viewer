## 5. 원본 대조 팩에 담아 주시면 좋은 것

각 회차에서 아래 셋이면 엔지니어가 일괄 적용할 수 있습니다.

1. **근거 확정** — 선지별로 「이 문장」 하나(또는 「비움」). 문장 id 가 아니라 **원문 어구**로 주셔도 됩니다
2. **`pat` 확정** — R1~R4·V / L1~L5 중 하나
3. **결론줄·인용부호** — 「표준 표기로 맞춘다」 또는 「현행 유지」 한 줄

적용은 `evidence_assign`(S-05 3중 안전장치) → 되읽기 검산 → 회차 게이트 5종 순으로 돕니다.
