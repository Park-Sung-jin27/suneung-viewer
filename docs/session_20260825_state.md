## 7. 협업 규율 — 바뀌지 않은 것

- `git add <path>` 한정. **`git add .`/`-A` 금지.** 데이터 수정과 검사도구 수정은 별도 커밋
- 공유 트리 `C:\Users\downf\suneung-viewer` 무접촉(읽기만). 다만 **런북은 그 트리 기준으로 적혀 있다**
  — 심사관·대표가 거기서 작업하기 때문이다(공유 트리에도 `pipeline/` 이 있다)
- `RELEASE_KEYS`·`RELEASED_KEYS`·`FREE_YEARS` 는 **프론트 소관**. 승격 기록의 `frontend_request` 에 키를 적어 넘긴다
- push 전 `git fetch origin` → ahead/behind 확인 → 필요시 **merge**(`all_data_204.json` 이 걸린 브랜치는 rebase 금지)
- 산출물(`free/`·`data-pro/`) 커밋 금지
- 4관문 순서 엄수: gate0(정답표) → gate1(QG) → gate3(화면 실측) → 대표 승인 → 승격 기록 → F-xx 노출
  **승격 기록을 gate3 전에 만들지 않는다**(D-132 에서 되돌린 전례)
