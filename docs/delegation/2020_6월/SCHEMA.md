## 필드 설명

| 필드 | 뜻 |
|---|---|
| `id` | 세트 id. 문학 `l`+연도+알파벳, 독서 `r`+연도+알파벳 |
| `title` | 지문 제목(작품명·주제). 원본에 없으면 내용으로 짧게 |
| `range` | `"34~36번"` 형태 |
| `sents[]` | 지문을 문장 단위로. `id`는 `<세트id>s<번호>` |
| `sents[].sentType` | `body`(산문) · `verse`(운문 행) · `workTag`((가)(나)) · `author`(- 작자 -) · `footnote`(각주 `*`) |
| `questions[].id` | 문항 번호(숫자) |
| `questions[].t` | 발문 |
| `questions[].bogi` | `<보기>` 가 있으면 그 내용, 없으면 생략 |
| `questions[].choices[].num` | 1~5 |
| `questions[].choices[].t` | 선지 원문 |

🔴 `ok` · `pat` · `analysis` · `cs_ids` 는 **넣지 않는다.** 예시에도 없다.
