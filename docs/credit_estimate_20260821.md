## 판단 재료

- **step3 는 어느 쪽이든 API 가 필요하다.** 해설은 위임 금지 사항이라 최소 $11 은 든다.
- 위임의 이점은 step2 비용($11.5~30)을 0으로 만드는 것.
- 위임의 비용은 **사람 손**이다: 19회차 × (붙여넣기 → 저장 → 검수 → 실패 시 재요청).
  검수는 자동이지만 왕복은 수동이다.
- **혼합안**: 노출 상위 몇 회차만 API 로 빠르게 처리하고 나머지를 위임하는 방법도 있다.
  노출 회차 17개 중 상위 5개(2015_9월B·2020_9월·2016_6월B·2014_9월A·2016_9월B)가
  전체 156문항 중 63문항(40%)을 차지한다.
