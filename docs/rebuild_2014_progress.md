# 2014수능 A/B OCR 오염 6 set 재구축 — 자동화 진행 파일

> **이 파일은 30분 간격 예약 작업의 유일한 연결고리다. 매 실행이 독립 세션(이전 대화 기억 없음)이므로 반드시 본 파일을 먼저 읽고, 작업 후 갱신한다.**

## 배경

- 2014수능 A/B는 **스캔본 PDF**(page당 텍스트 31~32자)라 데이터가 OCR로 깨짐.
- 출시(release)돼 있던 6 set가 OCR 오염/본문 빈 상태로 학생 노출됐다가 **2026-06-10 격리 완료** (dataLoader.js + constants.js 양쪽에서 제거).
- 격리 상태라 학생 노출 없음 → **시각 전사로 재구축 후 재출시** 예정.
- 정상 set(2014수능B 독서 r2014bB/cB/dB 등 06-09 재구축분)은 건드리지 않는다.

## 매 실행 절차 (한 번에 미완 set 1개만)

1. 본 파일에서 **첫 번째 ⬜ 미완 set**을 고른다.
2. `_done/{yearKey}/{yearKey}_시험지.pdf`에서 해당 range 지문 페이지를 찾는다.
   - 스캔본이라 텍스트 검색 불가 → 페이지를 fitz로 렌더(`matrix=fitz.Matrix(1.6,1.6)`)해서 Read로 눈으로 찾는다.
   - 추정: 2014 국어 문학(31~45)은 시험지 PDF의 **page index 9~15** 부근. 1~2장 렌더해 확인.
   - 출력은 반드시 `/sessions/.../mnt/outputs/`에 저장(다른 경로 권한 오류). 기존 파일 있으면 `rm -f` 먼저.
3. 지문 영역을 **고해상 crop**(`matrix=fitz.Matrix(4,4)`, 좌/우 컬럼 상·하 2분할)해서 Read로 **한 글자씩 정확히 전사**한다.
4. 정답표(`_done/{yearKey}/{yearKey}_정답.pdf`)는 **텍스트본**이다. `pdftotext -layout`로 추출 → 해당 문항 정답 확정 [Confirmed 근거].
5. 데이터 적용 (node 스크립트, `/tmp`에 작성 후 실행):
   - `set.sents` = 전사한 본문 (문장 단위 분할, 각 sent에 `para` 부여)
   - **운문은 `sentType:'verse'`**, 작가표시 `'author'`, 각주 `'footnote'`, `(가)(나)`·`<제N수>`는 `'workTag'`
   - 문항: `q.t`(발문), `q.bogi`, `q.choices[].t`(선지) 전사 / `questionType`(positive=긍정발문, negative=부정발문) / `ok`(정답표 기준: positive면 정답=ok:true, negative면 정답=ok:false) / `pat:null`, `analysis:''`, `cs_ids:[]` (해설·형광펜은 비움 — 재출시 전 LEGACY 해설 작업 때 채움)
   - 적용 전 `pipeline/backups/`에 백업.
6. **검증 (필수)**:
   - 정답표 대조: 각 문항 ok 분포 (positive→true 1개, negative→false 1개)
   - 5지선다: 모든 choices 길이 5
   - 본문 sent 수: 독서 ≥10, 문학 ≥5
   - para: 1부터 연속, 각주는 para 제외
   - **본문 원문 일치**: 전사본을 다시 한 번 crop과 대조 (OCR 오염이 출시됐던 근본 원인 = 이 검증 공백)
7. 본 파일의 해당 set 상태를 ✅로 바꾸고, **아래 "대표 확인 체크리스트"에 그 set에서 대표가 꼭 봐야 할 점을 1~3줄 추가**한다.
8. 모든 set이 ✅이면 "## 완료" 섹션을 채우고, 예약 작업을 중단(list_scheduled_tasks로 ID 확인 후 update로 비활성/삭제)한다.

## 운문(문학) 특별 주의

- **행 구분**: 시는 한 행 = 한 sent. 줄바꿈을 합치지 말 것.
- **연 구분**: 연 사이 빈 줄은 그대로 (sent 사이 구분).
- **작품 간 구분**: (가)/(나)/(다) 여러 작품이면 workTag로 경계.
- **마커**: ㉠~㉤, ⓐ~ⓔ 등 본문 marker는 원문 위치 그대로 인라인 삽입.
- **옛한글/한자**: 시험지 원문 그대로. PUA 깨짐 있으면 첫가끝/표준 유니코드.
