# 비공개 112세트 관문 실측 — 미공개 사유 분류

작성 2026-08-12 · 데이터 엔지니어 · 발주 dy

**데이터 353세트 중 241세트가 공개, 112세트 · 420문항이 비공개다.**
해설 필드는 채워져 있으므로 신규 제작이 아니라 "검수 후 등재" 문제다. 그 비용을 실측했다.

---

## ★ 결론 — 즉시 공개 가능 물량

| | 세트 | 문항 |
|---|---|---|
| 비공개 전체 | 112 | 420 |
| **관문 통과 (라)** | **75** | **279** |
| 미통과 | 37 | 141 |

**관문 통과는 필요조건이지 충분조건이 아니다.** 공개 전 세트당 대표 표본 3건 검수가 남는다(운용지침 §7-7·§7-14). 위 75세트는 "게이트가 막지 않는" 물량이지 "바로 공개해도 되는" 물량이 아니다.

## 분류 기준

| 분류 | 뜻 | 처방 |
|---|---|---|
| **(가)** 마커 정박 결손 | 발문·선지가 ㉠·ⓐ 같은 마커를 가리키는데 본문에 그 마커가 없다 | **PDF 대조 선행.** 정박 없이 해설을 만들면 환각이 나온다 |
| **(나)** 본문·보기 결손 | 본문이 비었거나, 발문이 보기를 요구하는데 보기가 비었다 | **PDF 대조 선행** |
| **(다)** 해설 형식 결함 | 관문이 CRITICAL로 잡은 항목이 있다 | 형식 수정으로 해결 가능 |
| **(라)** 통과 | 위 셋 어디에도 걸리지 않는다 | 남은 것은 대표 표본 검수뿐 |

## 이 문서가 말하지 않는 것

- **해설 내용이 맞는지**는 관문이 보지 않는다. 형식축만 본다(§7-7).
- 따라서 (라) 75세트도 **대표 표본 검수 전에는 공개할 수 없다.**
- `RELEASE_KEYS`는 이 실측에서 **수정하지 않았다.** 공개는 대표 승인 사항이다(AGENTS.md §4).
