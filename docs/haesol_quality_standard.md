## 6 차원 rubric

각 차원 = 정의 / 합격 기준 / 검사 방법([자동]=게이트, [검수]=사람).

### 1. 구조 (Structure)

- **정답(ok:true) = 3단 서술**: ① 📌 지문 근거 → ② 그 근거의 뜻풀이 → ③ 그래서 선지가 옳은 이유.
- **오답(ok:false) = 3단 대조**: ① 🔍 선지 분해(배경 / 주체·관점 / 핵심 주장) → ② 📌 지문 대조(선지가 _맞게_ 짚은 부분 인정 + 지문이 _실제로_ 말하는 바) → ③ ❌ 어긋난 지점 + pat 명명.
  - **선지 분해 완전성 ([Adopted 2026-06-22 대표])**: 선지에 핵심 주장이 둘 이상이면 _모든_ 조각을 분해하고, 오답 해설은 각 조각이 지문과 맞는지 **빠짐없이** 점검. 한 조각만 반박하고 끝내면 안 됨. (precedent: r2025c Q10③ — 선지가 '노이즈의 중요성 파악' + '종류→성능 영향 이해' 둘 다 주장하는데, 둘 다 지문에 없음('중요' 0건). 현 해설은 후자만 잡고 '중요성'을 놓쳤음 → 둘 다 짚어야 R3 완성.)
- **보기(<보기>) 문항 = 3단 대조 변주**: ① 보기 조건 분해 → ② 지문/작품의 실제 → ③ 어긋난 지점(보기 오독 / 보기 대입 오류 / 지문 오독 중 명시) + pat.
  - **보기 이중 점검 ([Adopted 2026-06-22 대표])**: 선지가 _보기와도 맞고 작품(지문)과도 맞는지_ 둘 다 확인. 요즘 보기는 포괄적이라 단순 논리 비교로 안 갈림 → "보기상 맞는 부분은 인정 → 선지가 적절하려면 작품에서 무엇이 나타나야 하는지 → 작품 실제가 그와 어긋남" 구조. (precedent: l2026a Q21② — 보기('우화→현실 중첩')는 부합하나, '위선'이 적절하려면 동의보감 장면에 위선이 있어야 하는데 작품은 노골적 탐욕뿐 → 오답.)
- **합격**: 해당 구조 블록이 모두 존재 + 결론줄(✅/❌)이 ok와 일치.
- **검사**: [자동] 결론줄=ok(F_content) · 3단 블록 존재(신설 후보) / [검수] 논리 타당성.
- precedent (대표 모델): 정답 3단 = r2026a Q2⑤(현행 유지 — 대표 "괜찮다") / 독서 오답 = r20276b Q5②(R2 관계전환)·r2025c Q10③(R3 과잉추론) / 문학 오답 = l2026a Q18②(L1 팩트왜곡) / 문학 의미과잉 = l2026a Q21②(L3) / 보기 대입 = l2026a Q21②.

### 2. 근거 (Evidence)

- 📌 지문 근거 = `sent.t`의 **verbatim**(정규화 없는 exact substring, §13⑥). 선지의 핵심 주장에 **직접 대응**.
- **cs_ids(형광펜) ⊇ 📌 인용 — 포함관계이지 동일이 아님 ([Adopted 2026-07-20 대표 결정])**
  - `cs_ids` = 그 선지의 **근거 문장 전체**. 학생이 선지를 클릭했을 때 켜져야 할 것 전부. **넓게**.
  - `📌` = 해설 지면 제약상 고른 **대표 근거 1~2개**. 좁게.
  - ∴ **📌 ⊆ cs_ids**. 📌에 없다는 이유로 cs_ids를 **축소 금지**(필요 시 추가만).
  - **금지 실증(2026-07-20)**: v2 재생성 중 cs를 📌와 1:1로 맞추려 l2026b 13선지·30개, l2026a 7개를 제거 → `Q22⑤`(정답)에서 (다) 가정 표현의 핵심 문장 `s29`, `Q22②`에서 (나) `s4`가 꺼짐. **해설이 다른 문장을 인용했다는 이유로 진짜 근거의 형광펜이 사라짐** = 핵심 차별점 훼손. 전량 원복.
  - 배경: 형광펜(선지↔지문 1:1)이 제품의 핵심 차별점이므로 **근거 커버리지가 해설 인용보다 우선**한다. 게이트의 근거완전성 축은 `📌 ⊆ cs`만 요구하며 역방향(`cs ⊆ 📌`)은 요구하지 않는다.
  - [검사] 자동: 📌 인용 sent가 cs에 있는지(근거완전성) / 수동: v2 재생성 전후 **cs 제거 건수 0** 확인.
- **근거 완전성 ([Adopted 2026-06-22 대표])**: 해설이 *추론에 사용한 모든 핵심 문장*이 📌·cs_ids 형광펜에 포함돼야 한다. 말줄임표(…)로 결정적 근거를 건너뛰면 안 됨. (precedent: l2026a Q18② — 해설은 "호랑이가 먼저 정체를 밝혔다"를 근거로 쓰는데, 그 문장 "나는 ㉠이 산중 지키는 호 생원 어른이로다…"이 📌에서 …로 누락돼 있었음 → 학생이 형광펜만 보면 해설 논리를 확인할 수 없음.) [검수] 해설↔형광펜 정합.
- **합격**: C_anchor exact 통과 + 근거가 선지 주장의 참/거짓을 실제로 가르는 문장 + 해설이 쓰는 근거가 형광펜에 모두 표시.
- **검사**: [자동] C_anchor_exact_fail(§13⑥) / [검수] 근거↔선지 대응 적합성.

### 3. 눈높이 (Readability — 타깃 3~4등급)

- 전문용어는 풀어서, 한 문장 한 호흡, 지시어("이·그·이러한") 남발 금지, 학생이 한 번에 이해.
- **톤 기준 (대표 모델 확정)**: ① 지문·선지의 말을 그대로 인용하되 풀어서 설명 ② "지문은 ~만 말한다 / 선지는 ~를 더했다(뒤바꿨다)" 식 대조 구문 ③ 한 문장에 한 논점, 짧은 단정형. (예: "지문의 호랑이는 탐욕을 감추기는커녕 '보는 대로 약 취해 먹기로만' 노골적으로 드러낸다." — l2026a Q21②)
- **검사**: [검수] (톤은 사람 — 자동화 어려움).

### 4. 간결 (Concision)

- "선지는 X, 지문은 Y, 그래서 뒤바뀜" 한 호흡. 군더더기·반복·동어반복 금지.
- 타 선지 비교/배제 근거 금지(각 선지 해설 자립 — §7).
- **분량 가이드 (대표 모델 기준)**: 오답 해설 = 🔍 분해 2~~3줄 + 📌 근거 1~~2문장 + ❌ 2~~3문장 = 전체 대략 3~~6문장. 📌 인용은 선지 판정에 필요한 만큼만(과인용 금지).
- **검사**: [반자동] `W_verbose`(~700자 초과 = 검수 트리거, 하드 차단 X) / [검수] 군더더기.

### 5. 패턴 정확 (Pattern accuracy)

- pat이 실제 오류 구조와 일치. **도메인 엄수**(독서 R1~~R4 / 문학 L1~~L5 / 공통 V).
- 메타발문 정답 = R3(§13⑨). R2 엄격 기준(대응 관계 역할 교환 = R1, §6) 준수.
- **합격**: pat이 analysis가 주장하는 오류 성격과 일치 + 도메인 정합.
- **검사**: [자동] C_label_domain_mismatch · C_pat_mismatch / [검수] 정확성.

### 6. 금지 (Forbidden)

- 내부 ID 노출(`[r2024cs11]` 등) · **LLM 스크래치패드 누출**("아, 잠깐!" / "정답 정보를 다시 보니" 류) · placeholder(`[?]`·TODO·`...`) · 타 선지 배제/정답 비교 블록 · PUA·비표준 글자.
- **검사**: [자동] H_analysis_id_leak · placeholder · **스크래치패드 누출 패턴(신설 후보)**.
