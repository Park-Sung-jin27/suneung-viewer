## ② 오탐확정 6건 — 손대지 않음

MeCab 이 복합조사 `으로서/에서의` 를 「으로 + 서의」로 오분석한 것이다.
파일 자체가 `오탐확정` 으로 분류했고, 실제로도 붙여 쓰는 것이 맞다.

```
자식으로▸서의   표현으로▸서의   개인으로▸서의
실천으로▸서의   고산구곡에▸서의  가장으로▸서의
```

## ③ 고전시가 9건 + 점선 뭉갬 — 행갈이 복원으로 함께 해소

`2015_9월B l20159d Q45` 의 `<보기 2>`(정철 「속미인곡」)가 두 가지로 망가져 있었다.

1. 행갈이가 사라져 시행이 한 줄로 이어붙음 (`돌아오니반벽청등…`) — 후보 9건 중 7건
2. 행 옆 구간 표시 `[가]~[마]` 와 지시선(점선)이 **앞으로 몰림**

원본 지면(360dpi)에서 확인한 구조:

```
모첨(茅簷) 찬 자리에 밤중만 돌아오니 ┐········ [가]
반벽청등(半壁靑燈)은 눌 위하여 밝았는고
```

점선은 조판 지시선이라 버리고, 행갈이를 되살리고, 구간 표시를 제 행 끝에 되돌렸다.
**16행 복원 · 구간표시 5개 제자리 · 글자 추가·손실 0.**

남은 2건(`소망을▸이루고자` · `순수하다는▸뜻이`)은 선지라 ①에서 띄움 처리됐다.

### 자체 발견 결함 — 「옮겨 적기」를 폐기했다

초안에서 시 전문을 이스케이프로 옮겨 적었다가 **8자를 잘못 썼다**.

```
簷→簝   靑→青   덧→덩   늙→닭   쁜→쁩   좇→젅   싀→싄
```

다중집합 검증이 이걸 잡았다. 그래서 「옮겨 적기」 자체를 버리고 **원본 문자열을
자르기만** 하는 방식으로 바꿨다 — 행 시작 어구(4~6자)로 경계를 찾고, 못 찾으면
그 자리에서 중단한다. 글자 생성이 0이 된다(§13⑬).

### 기존 353세트 16건 — 판정만 하고 손대지 않았다 `[확인 필요]`

「기존 변동 0」 원칙 때문이다. 판정은 전부 **붙임 유지**(합성어)로 본다.

```
공정거래위|원회가 → 공정거래위원회      정신|분석학적 → 정신분석학적
공생|발생설에    → 공생발생설          원생|미토콘드리 → 원생미토콘드리아
카디|오리핀이    → 카디오리핀          노예|제하에서  → 노예제하에서
```

다만 두 건은 **판정을 유보한다**:

- `2025_9월 l20259b Q27 bogi` `이문원|노종기` — 인명 두 개일 가능성이 있다.
  띄어야 한다면 기존 세트 수정이 필요하므로 대표 판단 사항.
- `2027_6월 l20276c Q30 bogi` `고전|소설에서는` — 「고전 소설」이 띄어쓰기 원칙이나,
  같은 회차 신규 세트는 PDF 가 붙여 썼다. 회차별 조판 차이일 수 있다.
