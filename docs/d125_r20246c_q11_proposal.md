# r20246c Q11 해설 재작성안 — 상신 (D-125 ③)

> **적용하지 않았다.** 심사관 판정 후 적용한다.
> 정답표 11번 = **③**, 데이터 `ok` 도 ③ — **정답은 맞다. 해설의 그래프 판독만 틀렸다.**

## `<보기>` 그래프 원본 판독

원본 3면, `<보기>` 상자 안(y 795~935). 그래프가 래스터 이미지라 텍스트 추출로는 점 위치가 나오지 않아
해당 영역을 400dpi 로 렌더해 눈으로 읽었다 `[Confirmed]`.

- 가로축 **흡착 세기** — 왼쪽 `약함` → 오른쪽 `강함`
- 세로축 **촉매 활성** — 아래 `낮음` → 위 `높음`
- 점 8개 중 넷에 ⓐⓑⓒⓓ 라벨이 붙어 있고, 전체가 **화산형(위로 볼록)** 이다

| 마커 | 가로(흡착 세기) | 세로(촉매 활성) |
|---|---|---|
| ⓐ | **가장 약함** (왼쪽 끝) | 낮음 |
| ⓑ | 약한 쪽 | 중간 |
| ⓒ | 중간 | **가장 높음** (꼭대기) |
| ⓓ | **가장 강함** (오른쪽 끝) | **가장 낮음** |

흡착 세기 순서는 **ⓐ < ⓑ < ⓒ < ⓓ** 다.
지문의 「흡착이 약하면 … 촉매 활성이 낮으며, 흡착이 너무 강하면 … 촉매 활성이 낮다」가
그대로 이 화산형 곡선이다. ⓐ 는 왼쪽 기슭, ⓓ 는 오른쪽 기슭, ⓒ 가 정상이다.

## 선지별 대조

| 선지 | ok | 그래프로 본 판정 | 현 해설 |
|---|---|---|---|
| #1 ⓐ보다 ⓑ가 더 느리게 | false | ⓑ 활성 > ⓐ → 더 빠르다. 부적절 ✅ | **맞다** |
| #2 ⓐ보다 ⓒ가 흡착량 더 적다 | false | ⓒ 흡착 > ⓐ → 흡착량도 많다. 부적절 ✅ | 🔴 **근거가 반대** |
| #3 ⓐ보다 ⓓ가 안정화 더 크다 | true | ⓓ 흡착 가장 강함 → 안정화 큼. 적절 ✅ | **맞다** (정답) |
| #4 ⓑ보다 ⓒ가 더 약하게 흡착 | false | ⓒ 흡착 > ⓑ → 더 강하다. 부적절 ✅ | **맞다** |
| #5 촉매 활성만 보면 ⓓ가 최적 | false | ⓓ 활성 **최저**. 부적절 ✅ | 🔴 **근거가 반대** |

**`ok` 배열은 다섯 선지 모두 맞다.** 고칠 것은 #5 와 #2 의 해설 본문뿐이다.

## #5 — 발주 ③ 대상 (재작성안)

지금 해설:
```
🔍 그래프에서 ⓓ가 가장 높은 촉매 활성을 보이며, 흡착 세기도 너무 약하거나 강하지 않은 적절한 중간 값이다.
❌ 지문과 어긋나는 부적절한 진술[?]
```

그래프와 **정반대**다. ⓓ 는 촉매 활성이 가장 낮고 흡착 세기는 가장 강한 쪽 끝이다.
「중간 값」인 것은 ⓒ 다. 게다가 결론줄에 `[?]` placeholder 가 남아 있다.

> **안**
> `📌 지문 근거: "이때 흡착 세기가 적절해야 한다. 흡착이 약하면 흡착량이 적어 촉매 활성이 낮으며, 흡착이 너무 강하면 흡착된 반응물이 지나치게 안정화되어 표면에서의 반응이 느려지므로 촉매 활성이 낮다."`
> `🔍 <보기> 그래프에서 ⓓ는 흡착 세기가 가장 강한 쪽 끝에 있고 촉매 활성은 가장 낮다. 지문이 말한 「흡착이 너무 강하면 흡착된 반응물이 지나치게 안정화되어 … 촉매 활성이 낮다」에 해당하는 자리다. 촉매 활성만 놓고 보면 가장 적합한 것은 활성이 가장 높은 ⓒ이지 ⓓ가 아니다.`
> `❌ 촉매 활성이 가장 낮은 ⓓ를 가장 적합한 활성 성분으로 본 부적절한 진술`

`pat` 은 현행 `R1` 을 유지한다 — 그래프 사실을 뒤집어 읽은 것이므로 사실 왜곡에 해당한다.
결론줄 문체는 이 세트 형제 선지(`❌ …한 부적절한 진술`)를 따랐다.

## #2 — 발주 밖 발견, 함께 상신

지금 해설:
```
🔍 그래프에서 ⓒ의 흡착 세기가 ⓐ보다 약하므로, 흡착량은 ⓒ가 ⓐ보다 '적다'. 선지는 이를 반대로 서술했다.
```

**자체 모순이다.** 「흡착량은 ⓒ가 ⓐ보다 적다」고 해 놓고 선지(`ⓐ보다 ⓒ에 흡착될 때 흡착량이 더 적다`)가
「반대로 서술했다」고 한다. 선지와 해설이 같은 말을 하고 있다.

원인은 그래프 판독이다. 실제로는 **ⓒ 의 흡착 세기가 ⓐ보다 강하다.**
결론(`❌`)은 우연히 맞았지만 근거가 통째로 반대다.

> **안**
> `📌 지문 근거: "흡착이 약하면 흡착량이 적어 촉매 활성이 낮으며"`
> `🔍 <보기> 그래프에서 ⓒ의 흡착 세기는 ⓐ보다 강하다(ⓐ가 왼쪽 끝, ⓒ가 중간). 지문이 「흡착이 약하면 흡착량이 적어」라 했으므로 흡착량도 ⓒ가 ⓐ보다 많다. 선지는 이를 반대로 서술했다.`
> `❌ 지문과 어긋나는 부적절한 진술 [팩트 왜곡]`

결론줄은 현행 그대로 두면 되고 `🔍` 한 줄만 바꾸면 된다. `pat` `R1` 유지.
