## 왜 이 6세트인가

2014 수능 A형·B형은 문항 59개가 아직 공개되지 않았습니다.
저희 자동 검사에서는 걸리는 것이 없어, **남은 것은 사람이 읽고 판단하는 일**입니다.
그래서 A형·B형에서 각각 독서 2세트·문학 1세트씩 골라 6세트를 뽑았습니다.

각 세트에서 문항 하나를 골라 선지 5개의 해설을 그대로 실었습니다.

봐 주실 것은 두 가지입니다.

1. **📌 로 표시된 인용이 시험지 지문에 실제로 있는 문장인가**
   (저희 자동 대조에서는 **6세트 30건 전부 있는 것으로 나왔습니다.**)
2. **🔍 로 시작하는 설명이 내용상 맞는가**
   이쪽은 자동으로 확인할 방법이 없습니다. **읽어 주셔야 합니다.**

해설 끝에 붙은 [R1]·[L5] 같은 대괄호 표시는 저희 내부 분류 코드입니다. 신경 쓰지 않으셔도 됩니다.

## 1. 2014 수능 A형 — 분젠·키르히호프의 분광 분석법

독서 · 16~18번 · **17번 문항**

### 문제

> 윗글을 이해한 내용으로 가장 적절한 것은?

### <보기>

없음 — 발문이 <보기>를 요구하지 않습니다.

### 선지별 해설

#### ① 

> 세슘의 존재는 분광 분석법이 창안되기 전에 확인되었다.

```
📌 지문 근거: "이 방법의 유효성은 그들이 새로운 금속 원소인 세슘과 루비듐을 발견함으로써 입증되었다."
🔍 세슘은 분광 분석법을 통해 '발견'된 새 원소이므로, 그 존재가 확인된 것은 분광 분석법이 창안된 '뒤'입니다. 창안되기 전에 확인되었다는 것은 순서가 반대입니다.
❌ 지문과 어긋나는 부적절한 진술 [R1]
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 이 방법의 유효성은 그들이 새로운 금속 원소인 세슘과 루비듐을 발견함으로써 입증되었다.


#### ② 

> 빛을 프리즘을 통해 분산시키면 빛의 파장이 길수록 굴절하는 각이 커진다.

```
📌 지문 근거: "빛이 띠 모양으로 분산되는 것은 빛이 파장이 짧을수록 굴절하는 각이 커지기 때문이다."
🔍 지문은 빛의 파장이 '짧을수록' 굴절하는 각이 커진다고 했습니다. 선지는 '길수록'이라고 하여 방향이 정반대입니다.
❌ 지문과 어긋나는 부적절한 진술 [R1]
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 빛이 띠 모양으로 분산되는 것은 빛이 파장이 짧을수록 굴절하는 각이 커지기 때문이다.


#### ③ **(정답)**

> 금속 원소 스펙트럼의 밝은 선의 위치는 불꽃의 온도를 높여도 변하지 않는다.

```
📌 지문 근거: "특정한 금속의 스펙트럼에서 띠엄띠엄 떨어진 밝은 선의 위치는 그 금속이 홑원소로 존재하든 다른 원소와 결합하여 존재하든 불꽃의 온도에 상관없이 항상 같다"
🔍 지문은 밝은 선의 위치가 그 금속이 홑원소든 결합 상태든, 그리고 불꽃의 온도와 상관없이 항상 같다고 했습니다. 따라서 불꽃의 온도를 높여도 금속 원소 스펙트럼의 밝은 선 위치는 변하지 않습니다.
✅ 지문과 일치하는 적절한 진술
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 이 과정에서 그들은 특정한 금속의 스펙트럼에서 띠엄띠엄 떨어진 밝은 선의 위치는 그 금속이 홑원소로 존재하든 다른 원소와 결합하여 존재하든 불꽃의 온도에 상관없이 항상 같다는 결론에 도달하였다.


#### ④ 

> 철이 태양 대기에 존재한다는 사실은 나트륨이 태양 대기에 존재한다는 사실보다 먼저 밝혀졌다.

```
📌 지문 근거: "그는 불꽃 반응 실험에서 관찰한 나트륨 스펙트럼의 두 개의 인접한 밝은 선과 1810년대 프라운호퍼가 프리즘을 이용하여 태양빛의 스펙트럼에서 발견한 검은 선들을 비교하는 과정에서"
🔍 지문은 태양 대기의 '나트륨'에 대해서만 설명할 뿐, '철'은 전혀 언급하지 않습니다. 철과 나트륨 중 무엇이 먼저 밝혀졌는지 비교할 근거 자체가 지문에 없으므로, 지문에 없는 내용을 끌어들인 추론입니다.
❌ 지문에서 확인할 수 없는 부적절한 진술 [R3]
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 그는 불꽃 반응 실험에서 관찰한 나트륨 스펙트럼의 두 개의 인접한 밝은 선과 1810년대 프라운호퍼가 프리즘을 이용하여 태양빛의 스펙트럼에서 발견한 검은 선들을 비교하는 과정에서, 태양빛의 스펙트럼에 검은 선이 나타나는 원인을 설명할 수 있었다.


#### ⑤ 

> 분젠은 두 종류 이상의 금속이 섞인 물질에서 나오는 각각의 불꽃색이 겹치는 현상을 막아 주는 버너를 고안하였다.

```
📌 지문 근거: "그는 버너 불꽃의 색을 제거한 개선된 버너를 고안함으로써 물질의 불꽃색을 더 잘 구별할 수 있도록 하였다."
🔍 분젠의 버너는 '불꽃 자체의 색을 제거'해 물질의 불꽃색을 잘 구별하게 한 것입니다. 두 금속이 섞여 색이 겹치는 문제는 이 버너로도 해결되지 않아 분간이 어려웠습니다. 따라서 '색 겹침을 막아 주는 버너'를 고안했다는 것은 지문과 다릅니다.
❌ 지문과 어긋나는 부적절한 진술 [R1]
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 그는 버너 불꽃의 색을 제거한 개선된 버너를 고안함으로써 물질의 불꽃색을 더 잘 구별할 수 있도록 하였다.

## 2. 2014 수능 A형 — 토인비의 문명 발생·성장 가설

독서 · 22~23번 · **23번 문항**

### 문제

> 윗글을 바탕으로 <보기>를 이해한 내용으로 적절하지 않은 것은?

### <보기>

```
빙하기가 끝나고 나서 세계 여러 지역의 기후는 크게 달라졌다. 서남아시아 일부 초원 지역의 경우는 급속히 사막화가 진행되었다. 이 지역에서 수렵 생활을 하던 어느 인간 집단은 세 가지 서로 다른 길을 걸었다. 첫째 집단은 그대로 머물러 생활양식을 유지하며 수렵 생활만 하다가 멸망의 길로 들어섰다. 둘째 집단은 생활양식만을 변경하여 그 지역에서 유목 생활을 하였다. 이들은 문명 단계에는 들어왔으나 더 이상의 발전이 없이 정체되고 말았다. 셋째 집단은 그 지역의 티그리스, 유프라테스 강 유역으로 이주한 다음, 농경 생활을 선택하여 새로운 고대 문명을 일구고 이어지는 문제들도 성공적으로 해결해 나갔다.
```

### 선지별 해설

#### ① **(정답)**

> 사막화는 서남아시아 일부 초원 지역 사람들이 당면했던 역경에 해당한다고 보아야겠군.

```
📌 지문 근거: "여기서 중요한 것은 그 환경이 역경이라는 점이다."
🔍 문명은 역경이라는 환경의 도전에 응전하는 과정에서 발생합니다. 따라서 사막화는 서남아시아 초원 지역 사람들이 당면한 역경에 해당합니다.
✅ 지문을 적용한 적절한 이해
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 여기서 중요한 것은 그 환경이 역경이라는 점이다.


#### ② **(정답)**

> 첫째 집단에서는 모방이 작용하는 방향이 선조들과 구세대를 향한다고 보아야겠군.

```
📌 지문 근거: "문명을 발생시키지 못한 원시 사회에서 모방은 선조들과 구세대를 향한다."
🔍 첫째 집단은 변화 없이 생활양식을 유지하다 멸망했습니다. 이는 모방이 선조와 구세대를 향해 인습이 지배하는, 문명을 발생시키지 못한 사회에 해당합니다.
✅ 지문을 적용한 적절한 이해
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 문명을 발생시키지 못한 원시 사회에서 모방은 선조들과 구세대를 향한다.


#### ③ 

> 둘째 집단은 문명을 발생시킨 후 이 집단의 창조적 소수가 계속된 새로운 도전들을 해결했다고 보아야겠군.

```
📌 지문 근거: "문명이 성장하기 위해서는 그 후에도 지속적으로 나타나는 문제, 즉 새로운 도전들을 해결해야만 한다."
🔍 <보기>에서 둘째 집단은 문명 단계에 들어왔으나 '더 이상의 발전이 없이 정체'되었습니다. 새로운 도전들을 계속 해결한 것이 아니므로, 창조적 소수가 계속된 도전을 해결했다는 이해는 보기와 어긋납니다.
❌ 보기와 어긋나는 부적절한 이해 [R1]
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 이렇게 성공적인 응전을 통해 나타난 문명이 성장하기 위해서는 그 후에도 지속적으로 나타나는 문제, 즉 새로운 도전들을 해결해야만 한다.


#### ④ **(정답)**

> 셋째 집단에서는 창조적 소수가 나타났고, 대중의 모방이 그들을 향한다고 보아야겠군.

```
📌 지문 근거: "모방이 창조적 소수에게로 향하는 사회에서는 인습의 권위를 인정하지 않으므로 문명이 지속적으로 성장한다."
🔍 셋째 집단은 새로운 문명을 일구고 이어지는 문제도 성공적으로 해결했습니다. 이는 창조적 소수가 나타났고 대중의 모방이 그들을 향하는, 지속적으로 성장하는 사회에 해당합니다.
✅ 지문을 적용한 적절한 이해
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 반대로 모방이 창조적 소수에게로 향하는 사회에서는 인습의 권위를 인정하지 않으므로 문명이 지속적으로 성장한다.


#### ⑤ **(정답)**

> 셋째 집단은 생활 터전과 생활양식을 모두 바꾸는 방식으로 환경의 변화에 응전하여 문명을 발생시켰다고 보아야겠군.

```
📌 지문 근거: "환경의 도전에 대해 성공적으로 응전하는 인간 집단이 문명을 발생시키고 성장시킨다."
🔍 셋째 집단은 생활 터전(강 유역으로 이주)과 생활양식(농경)을 모두 바꾸는 방식으로 사막화라는 환경의 도전에 성공적으로 응전하여 문명을 발생시켰습니다.
✅ 지문을 적용한 적절한 이해
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- 그에 의하면 환경의 도전에 대해 성공적으로 응전하는 인간 집단이 문명을 발생시키고 성장시킨다.

## 3. 2014 수능 A형 — 이형기, 「낙화」

문학 · 31~33번 · **32번 문항**

### 문제

> ㉠~㉤에 대한 이해로 가장 적절한 것은?

### <보기>

없음 — 발문이 <보기>를 요구하지 않습니다.

### 선지별 해설

#### ① 

> ㉠은 이별에 직면한 화자가 겪고 있는 내적인 방황을 드러내고 있다.

```
📌 지문 근거: "㉠분명히 알고 가는 이의"
🔍 ㉠은 가야 할 때를 '분명히 알고' 의연하게 떠나는 모습입니다. 이별 앞에서 갈피를 잡지 못하는 내적 방황을 드러내는 것이 아닙니다.
❌ 화자의 태도를 잘못 읽은 부적절한 이해 [L2]
```

📌 인용 1건 — 전부 시험지 지문에서 확인됨

형광펜으로 표시되는 근거 문장:

- ㉠분명히 알고 가는 이의


#### ②
