## r20266b — 수리 완료 (커밋 `75a8a9a` + `744867d`)

㉠(s16 절차주의 등장)과 ㉮(s35 임대차 계약 우선)은 내용이 전혀 다르다.
학생이 7번에서 엉뚱한 문장을 근거로 풀게 되는 상태였다.

- 발문 `㉠의 이유로` → `㉮의 이유로`
- 해설 4곳 `㉠` → `㉮` (#1 2곳 · #2 1곳 · #4 1곳)
- cs_ids 는 (나) 영역 문장(s34·s36·s23·s24·s25)으로 **원래 맞았다** — 발문 마커만 틀렸다

> ⚠ 커밋 `75a8a9a` 는 해설만 반영되고 발문은 안 써졌다. 원인은 아래 「조용한 실패」.
> `744867d` 에서 발문까지 실제 반영을 확인했다.

## l20266b — 가장 무거운 건

원본과 데이터의 마커 자리가 서로 다르다.

| | 원본 8면 | 데이터 |
|---|---|---|
| ⓐ | y 719.6 `ⓐ만물초 가는 길이 칠십 리 왕복이요` — **(가) 가사** | s48 `거리도 ⓐ 반은 솔밭 속에 묻히었다` — **(나) 산문** |
| ⓑ | y 302.3 `거리에서 ⓑ바다로 나가는 길이 좋다` | s55 `거리에서 ⓑ 바다로 나가는 길이 좋다` (공백만 다름) |
| ㉠ | 없음 | s29 `㉠ 만물초 가는 길이 칠십 리 왕복이요` |

23번은 `ⓐ, ⓑ에 대한 이해` 문항이다. 학생이 보는 ⓐ 가 원본과 다른 작품·다른 갈래의 문장이다.
선지 #1 `ⓐ는 화자가 날씨의 영향을 받지 않고 갈 수 있는 길이다` 의 근거도 s48 로 붙어 있는데,
원본대로면 s29(`청명한 일기에도 구름 끼면 못 보는데` 와 잇닿는 행)로 반박해야 한다.

**수리안** (승인 대기 — 본문 문장 수정이라 `sent_text_fix.mjs` 경로):
1. s29 `㉠ 만물초 가는 길이…` → `ⓐ만물초 가는 길이…`
2. s48 `거리도 ⓐ 반은 솔밭…` → `거리도 반은 솔밭…`
3. s55 `ⓑ 바다로` → `ⓑ바다로` (원본 일치, 경미)
4. Q23 선지 cs_ids 재부여는 **별건** — 근거 부여는 승인 사항

## r20226b · r20226c — 발문 마커 소실

둘 다 발문 첫 글자가 통째로 빠졌다. 본문 마커는 정확하다.

## 자체 발견 — 조용한 실패 (§13⑳)

발문만 바꾸는 SPEC 은 `n=0` 이라 **파일을 쓰지 않고도 「적용」이라 찍었다.**

- `n` 을 발문·bogi 변경에도 올린다
- 쓴 뒤 파일을 되읽어 SPEC 대로 반영됐는지 검산하고, 어긋나면 `exit 1`
- 이미 같은 값이면 「건너뜀」을 찍는다
