# pat 구분 기준 — R1 / R3 / R4 (독서 계열)

> 등재: 2026-09-02 · 판정 출처: 심사관 (D-190 트랙2 · r20279b F_content_reversed 3건)
> **향후 일관성을 위한 기준선이다.** 새 판정이 이것과 다르면 심사관 판정이 우선하고,
> 그때 이 문서를 고친다. 기존 데이터를 이 기준으로 소급 재분류하지 않는다.

## 세 유형이 갈리는 자리

같은 회차 같은 세트에서 세 유형이 한 번에 나왔다. 구분이 흐려지기 쉬운 조합이라
실제 사례를 그대로 남긴다.

| pat | 기준 | 사례 (`2027_9월::r20279b`) |
|---|---|---|
| **R4** 개념 혼합 | 서로 다른 **두 개념을 뒤섞은** 경우 | **Q7#2** — 표준적 입장의 「'행위자' 범주와 '피행위자' 범주가 **일치**」를 「범주가 **관계에 따라 달라짐**」과 섞었다. 범위 일치와 관계 의존은 별개의 개념이다. |
| **R1** 사실 왜곡 | 지문이 **명시적으로 부정하는 것**을 그대로 진술한 경우 | **Q7#5** — 표준적 입장에서 인간 이외의 종은 피행위자 범주에 들어오지 않는데, 선지가 다른 종을 '피행위자'라고 불렀다. 지문이 부정하는 지위를 부여했다. |
| **R3** 과잉 추론 | 지문·`<보기>`가 **배제한 범위로 넓혀** 추론한 경우 | **Q8#3** — `<보기>`가 「'전형적'은 **대부분의 구성원이 아니라** 대표적 구성원」이라 못박았는데, 선지가 대표 구성원의 특징을 인간 종 **전체**의 특징으로 건너뛰었다. |

## 한 줄 요약

- **두 개념을 섞었나** → R4
- **지문이 아니라고 한 것을 맞다고 했나** → R1
- **지문이 안 간 데까지 갔나** → R3

## 도메인 관례가 먼저다

`Q8#3`은 `<보기>` 규정을 잘못 대입한 것이라 **L5(보기 대입 오류)로도 읽힌다.**
그러나 **독서 세트에 L 계열을 넣으면 `W_domain_mismatch`가 뜬다**(독서 → R/V, 문학 → L).
심사관이 L5 를 기각하고 R3 로 확정했다.

> 판정 순서: **① 도메인(독서=R/V · 문학=L)** → ② 유형. 도메인을 어기는 유형 선택은
> 아무리 의미가 맞아도 채택하지 않는다. D-180 에서 LIVE 20건을 이 이유로 정합화했다.

## 근거 필수 여부와 얽힌다

`quality_gate.mjs`의 `REQUIRES_CS = R1·R2·R4·L1·L2·L4·L5`.
**R3·V·L3·null 은 의도적 면제**다(D-172 확인 — 버그가 아니다).

따라서 유형을 고르는 순간 `cs_ids` 의무가 따라온다.

- `Q7#2`(R4)·`Q7#5`(R1) → **근거 필수**. 둘 다 `s18`(표준적 입장 정의)을 편입했다.
- `Q8#3`(R3) → 면제. 다만 **기존 `cs_ids`(`s7`·`s8`)는 유지**했다 —
  면제는 「없어도 됨」이지 「있으면 안 됨」이 아니고, 정답 선지라 형광펜이 있는 편이
  학생에게 유리하다(심사관 판정).

`pat=V`만 반대다 — **근거를 가지면 `C_vpat_dirty` CRITICAL**이 된다. 채우지 않는다.
