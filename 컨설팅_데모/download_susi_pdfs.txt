=== adiga 수시 모집요강 2027 일괄 다운로드 코드 ===

사용 방법:
1. 크롬에서 다운로드 폴더를 원하는 곳으로 미리 변경
   설정 (chrome://settings/downloads) → 위치 → "변경" 클릭
   예: C:\Users\downf\suneung-viewer\모집요강_2027_수시
   "다운로드하기 전에 각 파일의 저장 위치 묻기" 체크 해제 (자동 저장)

2. adiga.kr 어느 페이지든 열어두기 (예: https://www.adiga.kr/man/inf/mainView.do)

3. F12 → Console → 아래 코드 전체 복사 + 엔터

4. 약 5-10분 후 214개 PDF가 다운로드 폴더에 저장됨

5. 폴더 정리 (선택): 학교별 정렬은 파일명 자동 부여로 이미 정렬됨

------ 코드 시작 ------

const TARGETS = /* 여기에 adiga_susi_2027_targets.json 내용 붙여넣기 */;

async function dlOne(item, idx) {
  const url = '/cmm/com/file/fileDown.do?fileId=' + item.fileId + '&fileSn=1&menuId=PCUVTINF2000&downLogYn=Y&unvCd=' + item.cd + '&searchSyr=2027';
  try {
    const r = await fetch(url, {credentials: 'include'});
    if (!r.ok) { console.warn('FAIL', idx, item.name, r.status); return false; }
    const blob = await r.blob();
    // content-disposition 파일명 확장자 추출 시도
    const cd = r.headers.get('content-disposition') || '';
    const ext_match = cd.match(/\.(pdf|hwp|hwpx|zip|docx)/i);
    const ext = ext_match ? ext_match[1].toLowerCase() : 'pdf';
    const safe_name = (item.name + '_' + (item.campus || '본교')).replace(/[\\\/:*?"<>|]/g, '_');
    const a = document.createElement('a');
    a.href = URL.createObjectURL(blob);
    a.download = safe_name + '_수시모집요강_2027.' + ext;
    document.body.appendChild(a); a.click(); document.body.removeChild(a);
    setTimeout(() => URL.revokeObjectURL(a.href), 5000);
    console.log('OK', idx + 1, '/', TARGETS.length, item.name, '(' + ext + ')');
    return true;
  } catch (e) {
    console.error('ERR', idx, item.name, e.message);
    return false;
  }
}

(async () => {
  let ok = 0, fail = 0;
  for (let i = 0; i < TARGETS.length; i++) {
    const success = await dlOne(TARGETS[i], i);
    if (success) ok++; else fail++;
    // 1초 간격 (서버 부담 + 브라우저 다운로드 안정)
    await new Promise(r => setTimeout(r, 1000));
  }
  console.log('=== 완료 ===');
  console.log('성공:', ok, '/ 실패:', fail, '/ 전체:', TARGETS.length);
})();

------ 코드 끝 ------

주의:
- 다운로드 폴더에 약 500MB-1GB 공간 필요 (PDF 평균 2-5MB × 214)
- 일부 학교는 HWP/HWPX/ZIP 형식일 수 있음 (코드가 확장자 자동 인식)
- 중간에 멈추려면 F5로 페이지 새로고침
