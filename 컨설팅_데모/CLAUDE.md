## 6. 시나리오 엔진 규칙

### 정시 (학생 환산점수 vs 작년 70cut)

```
ratio = (학생점수 - cut70) / cut_max
ratio >= 0.015 → 안전 (80%)
ratio >= -0.010 → 균형 (50%)
ratio >= -0.030 → 도전 (20%)
그 외 미달
```

### 수시 (학생 내신 vs 작년 70cut 등급)

```
diff = cut70_grade - student_grade  (학생이 cut보다 우수하면 +)
diff >= 1.0 → 안전 (80%)
diff >= 0.3 → 균형 (50%)
diff >= -0.3 → 도전 (20%)
그 외 미달
```

### 자동 필터

- 특별 전형 제외: 농어촌·기회균형·교육기회·특수교육·재외국민·특성화고·다문화·사회배려·장애·보훈
- 야간 학과 제외 (`(야)` 또는 `야간` 포함)
- 노이즈 학과명 제외 (헤더 잔존: `‘가/나/다’군`, `총계`, `소계` 등)
- 컷 outlier 제외 (정시: cut < 50, 수시: cut < 1 또는 > 9)
- 희망 계열 keyword 매칭 (FIELD_KEYWORDS)
- 희망 지역 매칭 (REGION_MAP)
