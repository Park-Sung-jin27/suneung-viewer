# 수시 교과전형 반영방법 수집 명세 (Codex 추출용)

> 목적: 수시 **교과전형 환산 계산기**에 쓸 학교별 반영방법을 정형 수집.
> 범위: **학생부교과 전형만**. 학생부종합(정성평가)·논술·실기는 제외(계산 불가/별개).
> 출처: 대학어디가(전형 평가기준) + 각 대학 수시 모집요강. **2027 미발표 → 작년(2026/2025) 기준 "잠정"으로 수집, 학년도 명시.**

## 1. 산출물

`교과반영방법_수시.csv` (또는 xlsx 시트), 1행 = 1학교·1전형. 예상 ~880행(220교 × 평균 4전형).

## 3. 표기 규칙 (검수 일관성)

- **반영교과**: `국·수·영·사·과` 형식, 가운뎃점(·) 구분. "전과목"이면 `전과목`.
- **비율**: 진로 + 일반 = **반드시 100**. (검수 1순위)
- **반영교과 인문/자연 분리**: 다르면 각각, 같으면 둘 다 동일 기입.
- **잠정 표시**: 2027 미확정이면 `반영학년도`에 작년 연도 + `비고`에 "잠정(작년 기준)".

## 4. 계산기 v1 환산 모델 (이 데이터로 무엇을 계산하나)

학생 입력: **교과별 평균 등급**(국·수·영·사·과, 일반선택) + **진로선택 평균 등급**(선택).

```
일반평균등급 = mean(반영교과(계열) 중 학생 일반선택 등급)
진로평균등급 = 학생 진로선택 평균
환산평균등급 = 일반평균 × (일반비율/100) + 진로평균 × (진로비율/100)
```

→ 출력: **환산 평균등급(1~9)** + 작년 `cut70_grade` 대비 위치.
**v1은 "평균등급"까지.** 등급→점수 변환표(석차변환등급 등)는 학교별 표가 별도로 필요 → v2.

## 5. 검수 항목 (Codex 자체 + 사람 검수)

1. 진로 + 일반 = 100 (아니면 flag)
2. 반영교과 표기 형식 일관 (·구분, 빈칸/오타 없음)
3. 학생부교과 전형만 (종합/논술/실기 섞이면 제외)
4. 대학코드 = universities.json unvCd와 매칭 가능
5. 누락 학교 / 반영방법 비공개 학교 목록 별도 산출(extraction_report.md)

## 6. 레드팀 검증 게이트 (정시와 동일 원칙)

전국 수집 전, **1개 학교·1개 전형의 실제 반영방법**을 위 형식으로 뽑아 보여줄 것.
그 1건이 형식·검수 항목을 통과하면 전국 수집 진행.
