### Task 1: 이상 데이터 필터 추가 (30분) ★★★★★

**파일**: `js/scenario_engine.js`

**위치**: `generateSusiScenarios` 함수 안. 기존 필터에 다음 추가:

```javascript
// 이상 데이터 제외
if (c.dept && (
  c.dept === "모집단위" || c.dept === "모집인원" ||
  c.dept.indexOf("모집단위") === 0 || c.dept.indexOf("모집인원") === 0

if (typeof c.cut70_grade === "number" && c.cut70_grade >= 8.5) continue;
if (!c.capacity || c.capacity === 0) continue;
```

`generateScenarios` (정시) 에도 동일 패턴:

```javascript

  dept.dept === "모집단위" || dept.dept === "모집인원" ||
  dept.dept.indexOf("모집단위") === 0 || dept.dept.indexOf("모집인원") === 0
```

### Task 4: 학과명 키워드 false positive 차단 (15-30분) ★★★

**파일**: `js/scenario_engine.js`

**위치**: `FIELD_KEYWORDS` 또는 `matchesWish` 함수

**옵션 A (단순)**: "공학" 키워드 리스트에서 "산업" 제거. 단 산업공학과·산업경영공학과도 빠짐.

**옵션 B (정확)**: 학과명에 "스포츠", "체육", "예술" 등 제외 키워드 list. 자연계열 매칭 시 이런 학과는 제외.

```javascript
var DEPT_EXCLUDE_FOR_NATURAL = ["스포츠", "체육", "예술", "음악", "미술", "디자인"];
// matchesWish 호출 후 추가 체크
if (student.track === "자연") {
  for (var ek = 0; ek < DEPT_EXCLUDE_FOR_NATURAL.length; ek++) {
    if (dept.dept.indexOf(DEPT_EXCLUDE_FOR_NATURAL[ek]) !== -1) return false;
  }
}
```

**검증**: 박준후 (자연·기계공학) → 연세대 스포츠응용산업학과가 추천에서 사라지면 성공.
