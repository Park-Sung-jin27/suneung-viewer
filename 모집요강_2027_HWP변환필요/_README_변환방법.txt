[모집요강 2027 HWP 변환 안내 — 갱신]

이 폴더에는 한컴 Office 변환이 필요한 .hwp 파일만 남아있습니다.

【변환할 파일】
   .hwp 파일 = 48개

【변환 절차】
1. 한컴 Office에서 .hwp 파일을 모두 일괄 변환
   - 한컴 2020+ : 도구 → PDF 변환 → 폴더 선택
   - 한컴 2018 이하: 수동 (각 파일 → 다른 이름으로 저장 → PDF)
2. 변환된 PDF는 **원래 이름 그대로** 유지 (예: 강원대학교_본교_시행계획_2027.pdf)
3. 변환 완료 후 → 상위 ../모집요강_2027/ 폴더로 모두 이동

【무시할 파일】
- _압축본_이미추출완료_무시/ : .hwpx 압축본. 안의 PDF/HWP는 이미 추출 완료
- _EGG_별도처리/ : 동의대학교 EGG 압축 파일. 별도 처리 필요
  - 알집/반디집으로 풀어서 안의 한컴 파일을 한컴 Office로 변환
  - 또는 동의대 입학처에서 직접 다운로드

【한 대학에 _1, _2 여러 파일?】
- 강원대처럼 _1, _2가 있으면 둘 다 변환
- 보통 _1 = 본교 시행계획, _2 = 외국인 시행계획
