# 짚이 콘텐츠 자동화 실행 매뉴얼 v1

> 타깃: 솔로 창업자 (성진) — 블로그·인스타 지속 게시
> 목표: 주 5~~7편 게시 + 사용자 실행 시간 주 2~~3시간 이내
> 작성: 2026-06-14

---

## 결론 (첫 줄)

**"모두 자동화"는 함정. 진짜 답은 "배치 작성 + AI 초안 + 예약 발행 + 콘텐츠 재활용" 4가지 조합.**
= 주 1회 2~3시간 몰입 → 1주치 콘텐츠 lock + 매일 자동 게시.

---

## 1. 왜 어려운가 (진단)

솔로 창업자 콘텐츠 실패 원인 [Inference]:

| 원인             | 실제 상황                                   |
| ---------------- | ------------------------------------------- |
| 매일 창의력 요구 | 매일 아이디어 짜내면 3주 안 burnout         |
| 완벽주의         | 1편에 4~5시간 = 지속 불가                   |
| 도구 파편화      | 노션·워드·인스타·블로그 왔다갔다            |
| 즉시 성과 X      | 3개월 노력 → 눈에 보이는 결과 X → 동기 하락 |
| 게시 시간 관리   | 최적 시간 놓치면 도달 감소                  |

**핵심 insight**: 문제는 "게시" 자체가 아니라 **"매일 신경 써야 한다는 부담"**. 이 부담을 없애는 게 자동화의 진짜 목적.

## 2. 자동화 4단계 조합

### Step 1 — 배치 작성 (Batching) ★★★★★

**개념**: 매일 1편 × 7일 X. **일요일 3시간 × 1일 = 1주치 7편** O.

**왜**:

- context switching 비용 (매번 "무엇을 쓸까" 고민) 제거
- 몰입 상태 = 생산성 3배 [Inference]
- 남은 6일은 짚이 뷰어 개발·강사 업무에 집중

**실행**:

- 일요일 오전 9~12시 = 콘텐츠 작성 lock
- 다른 요일 = 콘텐츠 X, 개발·업무만

### Step 2 — AI 초안 + 검수 (Hybrid) ★★★★★

**개념**: Claude가 초안 80% → 강사 검수 20% (30분/편).

**Claude 프롬프트 template** (본 세션 이후 매번 사용):

```
너는 짚이 카피라이터.

작품: [작품명]
yearKey: [예: 2024수능]
자산: Vol.1~4 마스터 가이드
톤: 지니쌤 (강사) 눈높이 학생·학부모
분량: 블로그 2,000자 / 인스타 캡션 500자

다음을 작성해줘:
1. 네이버 블로그 글 (SEO 정합)
2. 인스타 카드뉴스 7장 카피
3. 인스타 캡션 + 해시태그

출력 형식: markdown
```

이 프롬프트만 있으면 **1편 초안 = 3~5분 안 나옴**. 30분 검수 → 완성.

### Step 3 — 예약 발행 (Scheduling) ★★★★★

**개념**: 콘텐츠 저장소에 넣어두면 매일 자동 게시.

**도구 stack (2026 최적)**:

| 플랫폼             | 도구                    | 비용                 | 특징                                     |
| ------------------ | ----------------------- | -------------------- | ---------------------------------------- |
| 네이버 블로그      | **자체 예약 발행**      | 무료                 | 최대 30일 예약                           |
| 인스타 그램        | **Meta Business Suite** | 무료                 | 인스타 공식, 릴스 예약 X (피드·스토리 O) |
| 인스타 (릴스 포함) | Later·Buffer·Metricool  | 월 1~3만원           | Meta Business Suite 대안                 |
| 크로스 포스팅      | Zapier·Make.com         | 월 0~3만 (무료 tier) | 네이버 → 티스토리 자동 복제              |
| 콘텐츠 저장소      | **노션 (Notion)**       | 무료                 | 캘린더 view + template                   |

**권장 시작 조합**:

- 네이버 예약 발행 (자체)
- 인스타 = Meta Business Suite (자체 공식, 무료)
- 노션 = 콘텐츠 캘린더 (계획 + template 관리)

**총 월 비용 = 0원** (첫 6개월).

### Step 4 — 콘텐츠 재활용 (Repurposing) ★★★★

**개념**: Vol.1~4 각 chapter = 블로그 글 + 카드뉴스 + 릴스 3가지로 자동 확장.

**변환 매트릭스**:

```
Vol. 3 §3-3 관동별곡 분석 (마스터 가이드 안 1 chapter)
   ↓
   ├── 블로그 글: 2,000자 "관동별곡 서사 5줄 완벽 lock" (SEO 정합)
   ├── 인스타 카드뉴스: 7장 "관동별곡 = 정철 = 충신연주지사"
   ├── 인스타 릴스: 30~60초 강사 얼굴 영상 (선택)
   └── 카카오 채널 푸시: 요약 3줄 + 블로그 link
```

**즉, Vol.1~4 (총 chapter 약 40개) = 이론상 40 × 4 = 160편 콘텐츠 잠재**.
1주 5편 × 32주 = **8개월치 콘텐츠 lock**.

## 5. AI 초안 자동 생성 심화 (Claude 활용)

### 5-1. 블로그 글 template

```
[역할] 짚이 블로그 카피라이터
[타깃] 고3 학생·학부모

[톤] 신뢰형 + 실용형 (지니쌤 캐릭터)

[콘텐츠 소스]
Vol. [번호] §[챕터] [챕터명]
핵심 내용 요약:
- [3~5줄 요약 붙여넣기]

[출력 요구사항]
1. 제목 (28자 이내, SEO 키워드 포함)
2. 부제 (본문 요약 1줄)
3. 본문 (5~7개 소제목, 각 300~400자)
4. CTA (jippi.kr 방문 유도)
5. 관련 태그 5~7개

markdown 형식으로 출력.
```

### 5-2. 카드뉴스 7장 template

```
[역할] 짚이 카드뉴스 카피라이터

[콘텐츠 소스]
[블로그 글 붙여넣기]

[출력 요구사항]
- Card 1 HOOK: 질문형 + 이모지
- Card 2 진단: 학생 현재 상황
- Card 3 핵심: huge font 1줄
- Card 4 사례: 실제 기출 (지문/선지 박스)
- Card 5 식별법: 3단계
- Card 6 짚이 솔루션
- Card 7 CTA: jippi.kr

거부 path 점검 후 출력.
```

이 template 2개만 있으면 매주 콘텐츠 생산 시간 **80% 절약**.

## 6. 완전 자동화 함정 (하지 말 것)

### 함정 1 — AI가 다 쓰게 하기

- 강사 검수 없이 발행 = 사실 오류 risk
- 학생 신뢰 즉시 손상
- **최소 30분/편 검수 의무**

### 함정 2 — 6개 플랫폼 동시 진입

- 네이버 + 티스토리 + 인스타 + 유튜브 + 카카오 + 페북 = burnout 확실
- **초기 6개월 = 네이버 + 인스타 2개만**

### 함정 3 — 완벽한 도구 stack 찾기

- Zapier·Make.com·Airtable·Notion·Buffer·Later 등 조사에 1주 낭비
- **일단 시작 → 3개월 후 최적화**

### 함정 4 — 매일 실시간 반응 체크

- 게시 후 좋아요·댓글 3시간 확인 = 시간 낭비
- **주 1회 (일요일) 통계만 확인**

## 9. 만약 그래도 안 될 때 대안

### 대안 A — 주 3편으로 축소

5편 → 3편. 월·수·금 블로그 + 화·목 인스타.

- 실행 시간 = 주 1.5시간
- 트래픽 성장 속도 = 60~70% 유지

### 대안 B — 인스타 우선 + 블로그는 월 4편

카드뉴스가 짚이 brand + 학생 학부모 심리 정합 강함.

- 인스타 주 3편 + 블로그 주 1편
- 실행 시간 = 주 1.5시간

### 대안 C — 강사 사업 우선, 콘텐츠는 월 4편만

블로그 주 1편 + 인스타 주 1편.

- 실행 시간 = 주 45분
- 최소한 brand 노출 유지

**어떤 대안이든 "0"보다는 강력.**
