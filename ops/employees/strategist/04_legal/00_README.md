## ✅ 변호사 자문 전 체크리스트

### A. 사업자 정보 [기입] 항목 채우기

다음 placeholder를 채운 후 변호사에게 전달:

- `[성진]` → 본인 성함
- `[발급 후 기입]` → 사업자등록번호 (홈택스 신청 후)
- `[기입]` → 사업장 소재지 (자택 vs 별도 사무실 결정)
- `[기입]` → 대표 연락처, 대표 이메일
- `[발급 후 기입]` → 통신판매업 신고번호
- `[2026년 ○월 ○일]` → 시행 예정일
- `[14,900원]` 등 가격 → 최종 결정 가격 확정

### B. 사업자등록 + 통신판매업 신고 선행

약관 시행일 이전에 다음 절차 완료:

1. **사업자등록** (홈택스, 온라인 30분, 무료)
   - 개인사업자
   - 업종: "온라인 교육 서비스" + "전자상거래" 추가
2. **통신판매업 신고** (관할 구청, 1주일)
   - B2C 결제 받기 위한 필수 절차
   - 사업자등록증 + 신청서 + 등록면허세

3. **개인정보처리책임자 지정** (본인)

### C. 변호사 자문 질문 list (필수 10개)

자문 시점에 다음 질문 우선 진행:

1. **만 14세 미만 회원 정책**
   - 본 제품 타깃에 중학생 포함 시 법정대리인 동의 절차
   - 약관 제5조 적정성 검토

2. **자동결제·청약철회**
   - 7일 청약철회 + 일부 사용 비례 차감
   - 메가스터디 모델 직접 모방 적정 여부

3. **AI 자동화 결정 고지**
   - 2024 개인정보보호법 개정으로 AI 결정 고지 의무화
   - 처리방침 제8조 충분성

4. **학부모 리포트 동의 절차**
   - 학생 동의 vs 학부모 동의 분리 적정성

5. **B2B 학원 계약**
   - 학원이 등록한 학생의 개인정보 처리 책임 분담
   - B2B 약관 제7조 적정성

6. **AI 분석 결과 면책**
   - 학생 등급 변화·시험 결과에 대한 면책 조항 효력

7. **환불 위약금 10%**
   - 연간 결제 위약금 10%의 약관규제법 적합성
   - 불공정 약관 조사 가능성

8. **준거법·관할 법원**
   - 회사 소재지 관할 조항의 약관규제법 적합성

9. **표준약관 사용 가능 분야**
   - 본 제품이 공정거래위원회 표준약관 적용 분야인지 확인

10. **개인정보보호위원회 신고 의무**
    - 매출 규모·회원 수에 따른 신고 의무 발생 시점

### D. 자문 비용 추정

- 변호사 1회 자문 (1시간 미팅): **20~50만원**
- 약관 검토 + 수정 패키지: **50~150만원**
- 추천 방법: **로톡(LawTalk)** 또는 **로앤컴퍼니** 통해 "스타트업 약관 검토" 변호사 검색

### E. 약관 시행 후 운영

1. **약관 동의 절차 기록 보존**
   - 회원가입 시점, 약관 버전, 동의 IP 영구 기록
   - 분쟁 시 입증 자료

2. **약관 변경 이력 관리**
   - 모든 변경에 v0.2, v0.3 버전 명시
   - 변경 일자 + 변경 사유 사이트 별도 page 공개
   - 변경 이력 누락 시 분쟁 패소 risk

3. **약관 변경 공지 의무**
   - 일반 변경: 7일 전 공지
   - 회원 불리 변경: 30일 전 공지 + 별도 동의

## ⚠️ 절대 하지 말 것

1. ❌ **변호사 검토 없이 실서비스 적용 금지** — base draft 그대로 사용 시 약관규제법 위반 risk + 분쟁 시 무효 risk
2. ❌ **메가스터디·콴다 약관 그대로 복사·붙여넣기 금지** — 저작권 위반 risk. 본 초안은 표준 조항 기반 재작성됨.
3. ❌ **만 14세 미만 회원 무동의 가입 허용 금지** — 개인정보보호법 위반. 적발 시 과태료 1,000만원~
4. ❌ **약관 변경 시 공지 없이 적용 금지** — 변경 효력 X
5. ❌ **B2B 약관에 "회사는 어떠한 손해에도 책임지지 않는다" 조항 금지** — 약관규제법상 무효
6. ❌ **결제 후 환불 거부 정책 도입 금지** — 전자상거래법 청약철회권 침해
