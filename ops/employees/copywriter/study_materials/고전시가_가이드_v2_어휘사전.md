# 짚이 고전시가 어휘 사전 v1

## 13년치 기출 본문 추출 (2014~2027학년도)

> 짚이 데이터 24개 고전시가 set 본문 전수 분석
> 작성: 2026-06-12
> 타깃: 고전시가 1차 해석이 어려운 고3 학생
> ⚠ **v1 = 1차 자동 추출 + 일반 지식 기반 풀이. 강사(성진) 검수 후 v2 lock 의무**

---

## 사용 안내

본 사전은 짚이 데이터 안 13년치 고전시가 set 24개 본문에서 자동 추출한 어휘입니다.

- **Part 1**: 한자 어휘 (사대부 시조·가사 핵심) — 빈출 31개
- **Part 2**: 옛한글 어휘 (첫가끝 자모) — 23개
- **Part 3**: 고전 한글 어휘 (현대어와 의미 차이) — 30개

각 어휘는 다음 정보를 포함합니다:

- 표기 (한자/옛한글/한글)
- 음 (한글 발음)
- 의미 풀이
- 출제 출처 (yearKey · 작품)

**📌 강사 검수 영역**: 각 어휘 옆 `[검수 필요]` 표시는 일반 지식 기반 풀이. 강사 11년 경력 검수 후 lock 의무.

### 2-3. 옛한글 학습 핵심 패턴

| 옛한글 자모                 | 현대 변환                                        |
| --------------------------- | ------------------------------------------------ |
| ㅎ + ㆍ (아래아) → **ᄒᆞ**  | 하 (예: ᄒᆞ다 → 하다)                            |
| ㅁ + ㆍ → **ᄆᆞ**           | 마 (예: ᄆᆞ음 → 마음)                            |
| ㄴ + ㆍ → **ᄂᆞ**           | 나 (예: ᄂᆞᆫ → 는)                               |
| ㄱ + ㆍ → **ᄀᆞ**           | 가 (예: ᄀᆞᆺ → 같)                               |
| **ᄒᆡ, ᄆᆡ, ᄂᆡ** (ㅐ 변형) | 해, 매, 내 (예: 아ᄒᆡ → 아이/아해, 새ᄒᆡ → 새해) |

**핵심 lock**: 옛한글 아래아(ㆍ)는 현대 한글 ㅏ 또는 ㅗ로 변환. **ᄒᆞ다 = 하다, ᄆᆞ음 = 마음** lock 1번이면 거의 모든 옛한글 1차 해독 가능.
