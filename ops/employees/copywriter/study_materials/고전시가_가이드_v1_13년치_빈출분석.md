## 들어가며 — 왜 13년치인가?

대형 인강·교재의 고전시가 자료는 **최대 5수능 기출** 범위입니다. 그러나 출제 트렌드는 **3~5년 주기로 반복**되며, 일부 작품은 **재출제**됩니다.

짚이 데이터는 **2014학년도 ~ 2027학년도 (14년치 / 49 yearKey)** 전수 분석을 보유합니다. 본 가이드는 이 데이터를 기반으로 **학생이 무엇부터 공부해야 할지** 우선순위를 lock합니다.

**핵심 발견**:
- 13년치에서 같은 작품이 **2회 이상 출제**된 사례가 다수 (예: 김인겸 일동장유가)
- 사설시조가 최근 3년 연속 출제 = 명백한 트렌드
- 정철 작품이 4회 출제 = 빈출 작가 1위
- 조선 후기 가사 (탄궁가·농가·갑민가·북새곡 등) 강세

## 1. 한눈에 — 13년치 출제 통계

### 1-1. 갈래별 분포

| 갈래 | 출제 횟수 | 비율 |
|---|---|---|
| **시조** (평시조·연시조·사설시조) | 23회 | 약 55% |
| **가사** | 16회 | 약 38% |
| 악장 (용비어천가) | 1회 | 2.4% |
| 고려가요 (만전춘별사) | 1회 | 2.4% |
| 경기체가·향가 | 0회 | 0% |

**시사점**: 시조 + 가사 = 93% 차지. **이 둘만 집중해도 출제 영역의 대부분 cover**. 향가·경기체가는 14년 동안 0회 (다른 교재에서는 가르치지만, 실 출제 X).

### 1-2. 시대별 분포

| 시대 | 출제 횟수 | 비율 |
|---|---|---|
| **조선 후기** | 14회 | 약 45% |
| **조선 중기** | 10회 | 약 32% |
| 조선 초기 | 4회 | 약 13% |
| 고려말 | 2회 | 약 6% |
| 고려 | 1회 | 약 3% |

**시사점**: **조선 후기 + 중기 = 77%**. 학생 우선 학습 영역. 조선 후기 가사 (탄궁가·농가·갑민가 등)와 조선 중기 시조 (도산십이곡·오우가·강호사시가 등) 집중.

### 1-3. 빈출 작가 top 5

| 순위 | 작가 | 출제 | 대표 작품 |
|---|---|---|---|
| 1 | **정철** | **4회** | 관동별곡·사미인곡·속미인곡·훈민가 |
| 2 | 김인겸 | 2회 | 일동장유가 (2019·2024수능 **재출제**) |
| 2 | 정훈 | 2회 | 탄궁가 |
| 2 | 위백규 | 2회 | 농가 |

**시사점**: 정철 1명만으로 4회 = **정철 작품 학습은 가성비 최고**. 김인겸 일동장유가는 **재출제 작품** = 다시 나올 가능성 보장.

## 2. 우선순위 ★★★★★ — 사설시조 (최근 3년 연속)

### 사실
- **2024_9월 모의평가** 출제
- **2025학년도 수능** 출제 (갑민가 + 사설시조)
- **2026학년도 수능** 출제 (북새곡 + 사설시조 + 사설시조 — 한 set 안 사설시조 2편)

**3년 연속 + 한 set 안 2편 = 명백한 출제 트렌드**

### 학습 path
1. **사설시조의 형식 lock**: 평시조 3장 6구 형식 깨고 중장에서 사설 부연. 운율 변화 인지.
2. **빈출 주제**: 서민 정서 · 풍자 · 해학 · 사랑 (특히 익명·익명 작자 미상이 주류)
3. **화자 정서 분류**: 평민 화자가 다수. 사대부 시조 화자 (자연 친화·유교 가치)와 명확 구분.
4. **선지 빈출 패턴**: "화자가 ~을 풍자하고 있다", "화자가 ~을 해학적으로 표현하고 있다"

### 짚이 차별점
사설시조는 본문 옛한글·고어가 평시조보다 많고 길어서 1차 해석 부담 大. 짚이 뷰어에서 **선지마다 본문 형광펜 매핑**으로 1차 해석 부담 해소.

## 3. 우선순위 ★★★★ — 정철 가사 2종 (관동별곡·사미인곡)

### 사실
- **정철 = 4회 출제 빈출 작가 1위**
- 관동별곡 = 2회 (2015수능B + 2021_6월)
- 사미인곡 = 1회 (2021수능)
- 훈민가·속미인곡 등 정철 작품 다수 잠재

### 학습 path
1. **정철 세계관 lock**: 충신연주지사 (임금에게 충성 + 그리움). 사미인곡·속미인곡 둘 다 핵심 정서.
2. **관동별곡 핵심**: 기행 가사. 동해안 경관 묘사 + 화자의 감회·우국지정. 4·4조 정형 율격.
3. **사미인곡 핵심**: 충신연주지사 가사의 대표작. 임금을 임으로 표현하는 비유 구조.
4. **빈출 표현**: "님" (임금), "흰 옷자락" (정절), "구름" (간신·장애물)

### 시험장 적용
정철 작품은 **선지에 작가 의도 ('우국지정' '연군의 정' '자연 친화' 등)** 가 빈출. 작품 모르면 선지에서 함정 인식 X. **정철 = 사대부 화자 + 충신연주지사** lock.

## 4. 우선순위 ★★★★ — 조선 후기 가사 5선

### 13년치 출제 list

| 작품 | 작가 | 출제 |
|---|---|---|
| **일동장유가** | **김인겸** | **2019수능 + 2024수능 (재출제)** |
| 탄궁가 | 정훈 | 2022수능 + 2016_9월A |

| 갑민가 | 작자 미상 | 2025수능 |

### 학습 path
1. **조선 후기 가사 공통 lock**: 현실 반영 + 서민 정서 + 비판 의식. 사대부 가사 (자연 친화·유교 가치)와 명확 구분.
2. **일동장유가**: 김인겸의 일본 사행 기행 가사. **재출제 작품**으로 다시 나올 가능성 ★★★★★.
3. **탄궁가**: 가난에 대한 탄식과 수용. 화자의 양가 감정 인지.
4. **농가**: 농민의 일상과 노동. 위백규 = 농촌 실학자 시인.
5. **갑민가·북새곡**: 변방 백성의 고통 + 정부 비판. 최근 2년 (2025·2026수능) 연속 출제.

### 시험장 적용
조선 후기 가사 선지는 **"현실 비판" / "백성의 고통" / "양반 풍자"** 표현 빈출. 사대부 가사 표현 ("자연 친화" "임금에 대한 충성") 과 명확 구분.

## 6. 같이 출제되는 패턴 (복합 갈래)

13년치 분석에서 발견된 **출제 트렌드**:

### 패턴 A: 시조 + 가사 (같은 시대)
- 2026수능: 북새곡 (가사) + 사설시조 + 사설시조
- 2025수능: 갑민가 (가사) + 사설시조
- 2024수능: 일동장유가 (가사) + 화암구곡 (시조)
- 2022수능: 탄궁가 (가사) + 농가 (시조)

→ **가사 + 시조 함께 출제 = 거의 매년**. 학생은 두 갈래 모두 학습 의무.

### 패턴 B: 시조 + 현대시
- 2019_9월: 한거십팔곡 (시조) + 추억에서 (현대시)
- 2020_6월: 유원십이곡 (시조) + 조용 (수필)

→ 갈래 비교 문항 출제. 화자 정서·태도 공통점·차이점 분석 빈출.

### 패턴 C: 같은 주제 다른 작품
- 2022수능 (탄궁가 + 농가) = 둘 다 농촌 생활 주제
- 2023수능 (도산십이곡 + 지수정가 + 겸재의 빛) = 모두 자연·예술 주제

→ 보기 대입 오류 (L5) 빈출. 보기에서 제시한 주제와 각 작품의 정합 확인 의무.
