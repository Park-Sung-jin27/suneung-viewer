짚이 프로필 로고 — 4가지 ver

1080×1080 (1:1 정사각형) · PNG export 2x · 인스타·김과외·숨고·카톡 등 프로필 정합

ver A — 다크

인스타 + 카드뉴스 정합 (피드 안 강조)
짚이
권장: 인스타 프로필 · 카톡 채널 · 유튜브 채널

ver B — 라이트

김과외 + 숨고 정합 (전문성 lock)
짚이
권장: 김과외 프로필 · 숨고 프로필 · 명함

ver C — 펜촉 단독

투명 배경 · 다양한 배경 적용용
권장: 워터마크 · favicon · 인쇄물 · 외부 배경 위 적용

ver D — 한글 + 영문

국제 노출 path 정합 (한글 + Jippi)
짚이
Jippi
권장: 웹사이트 헤더 · 영문 노출 path · jippi.kr

💡 사용 가이드

인스타 프로필 → ver A 권장. 피드 카드뉴스 (다크 그린 배경)와 시각 정합.
김과외 / 숨고 프로필 → ver B 권장. 학부모 신뢰형 (라이트 배경 + 형광펜 강조).
jippi.kr 웹사이트 헤더 → ver D 권장 (한글 + 영문 콤보).
워터마크 / favicon → ver C 권장 (투명 배경).

📌 다운로드 PNG는 2160×2160 (2x 해상도)로 export됩니다. 인스타·김과외·숨고 등 모든 플랫폼 권장 해상도 충족.
📌 ver C (투명)는 PNG로 export되며, 배경이 자동으로 투명 처리됩니다.
