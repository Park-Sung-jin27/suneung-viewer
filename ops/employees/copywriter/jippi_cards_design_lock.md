## 13. 신규 시리즈 작성 workflow

```
1. 사용자 요청 수신 → 주제 + 메시지 확인
2. CLAUDE.md 거부 path 1차 점검
3. 7장 카피 초안 작성 (HOOK→진단→핵심→인사이트→솔루션①②→CTA)
4. 거부 path 2차 점검 (각 카드 1건씩)
5. template 복사 → 카피 영역만 교체
6. 캡션 + 해시태그 작성 (구조 lock 정합)
7. file 출력 → present_files
8. 사용자 시각 검수 → 수정 또는 게시 진행
```
