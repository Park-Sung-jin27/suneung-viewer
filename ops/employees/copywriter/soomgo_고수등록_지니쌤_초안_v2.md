## ① 서비스 상세 설명 (약 1,650자 — v1과 동일)

선지 4개 중 2개에서 망설인 적 있다면, 학년·내신·점수와 무관하게 원인은 한 가지입니다 — '왜 오답인지'를 모르기 때문입니다.

저는 한양대학교 경영학과 14학번이고, 동대학 조직인사 전공 석사를 졸업했습니다. 고등학교 내신 1.01로 졸업한 후 대학교 진학과 동시에 과외를 시작해 11년 동안 50명 이상의 학생을 직접 지도해 왔습니다. 강북성북교육지원청에 등록된 개인 교습자이며, 대형 과외 매칭 플랫폼에서 47건의 과외를 성사한 실적이 있습니다.

[전문 영역]
국어 (독서·문학·언어와매체·화법과작문·논술), 영어 (어휘·문법·구조 독해), 수학 (공통·미적분·확률과통계·기하), 입시 컨설팅 (수시 시나리오 산출·정시 백업안·자기소개서·면접·세특 관리), 검정고시 (전 과목), 논술 (인문·약술형). 한 명의 강사가 입시 전 과정을 통합 지도할 수 있다는 점이 가장 큰 강점입니다. 여러 강사 사이에서 발생하는 소통 비용과 학습 방향 불일치를 사전에 차단합니다.

[차별점 1 — 자체 분석 DB]
수능 국어 최근 5개년 전 문항 (총 204문항)을 11년 강의 경력을 기반으로 직접 분석해 자체 데이터베이스로 축적했습니다. 선지마다 지문 근거를 형광펜으로 1:1 매핑하는 풀이법과, 9가지 오답 패턴 자동 분류 노하우를 학생에게 전수합니다. 학생이 어느 패턴에 약한지가 회차마다 누적되어, 본인 약점 영역을 정확히 진단할 수 있습니다. 일반적으로 4~6주차에 학생 본인이 풀이 후 스스로 약점 패턴을 진단할 수 있게 되며, 이는 자기주도학습의 핵심 단계입니다.

[차별점 2 — 자체 입시 컨설팅 시스템]
수시·정시 입시 컨설팅을 위해 자체 분석 시스템을 개발해 운영합니다. 학생 점수·내신·희망 계열·지역·제약을 입력하면 수시 3안 (안전 약 80% / 균형 약 50% / 도전 약 20%) + 정시 백업안 + 균형안 근거 + 리스크 + 학부모 1페이지 요약이 자동 산출됩니다. 30개 대학 환산공식과 9년 추이 데이터를 기반으로 학생 본인에게 최적인 시나리오를 사전 산출하므로, 9월 수시 시즌·12월 정시 시즌에 학부모께서 결정해야 할 사항을 한 페이지로 정리해 전달드립니다.

[차별점 3 — 한양대 조직인사 석사 background]
대학원에서 조직인사 전공으로 석사 학위를 받았습니다. 이 background를 기반으로 학생 개개인의 성격·강점·약점을 진단하고, 학생 본인에게 가장 맞는 학습 방식·진로 path를 안내합니다. 단순한 강의가 아닌 학생 개별 진단 기반의 지도를 제공합니다.

[지도 방식]
1대1 또는 소규모 그룹 (2~3명, 정합성 확보 시). 회당 60·90·120분 중 학생 학년·과목에 따라 권장. 일반적으로 고등 국어·수학은 90분 기준이 효율적입니다. 학습 진도·이해도·과제 수행률·다음 주기 계획을 한 달 단위 (또는 학부모 요청 주기) 카톡·문자로 정리해 전달드립니다. 수업 외 시간에도 카톡 질의응답을 기본 포함으로 제공하며, 본 강사가 늘 태블릿을 지참하므로 최대한 빠르게 답변드립니다.

[지도 철학]
무엇을 공부할지가 아니라, 어떻게 공부할지를 가르칩니다. 학생이 졸업한 후에도 스스로 공부할 수 있는 자기주도학습 습관 형성이 핵심 목표입니다. 학생에게는 멘토처럼, 학부모께는 전문가처럼 — 목표 달성까지 최선을 다하겠습니다.

[학부모께 약속]
성과 보장 표현은 사용하지 않습니다. 학생 본인의 노력과 환경이 결정 요인이며, 강사는 가장 효율적인 path와 도구를 제공할 뿐입니다. 다만 11년 동안 축적한 자체 분석 DB와 컨설팅 시스템을 통해 학생 약점을 정확히 진단하고, 개선 path를 단계별로 안내드립니다. 첫 30분 무상 상담을 통해 학생 현 상태 진단과 학습 path 안내를 받으실 수 있습니다.

### Q1. 서비스가 시작되기 전 어떤 절차로 진행하나요? (약 480자)

본 강사는 학생·학부모의 신중한 결정을 보장하기 위해 4단계 절차를 운영합니다.

**1단계 — 1차 상담 (무료, 약 30분, 카톡 또는 화상)**
학생 학년·계열·현 성적·희망 학과·기존 학습 이력을 듣고 본 강사 지도 영역과의 정합도를 확인합니다. 본 강사의 강점과 한계를 정직하게 안내드립니다.

**2단계 — 진단 + 시범과외 (약 60분, 약 5만원, 수업 성사 시 면제)**
실제 문제 풀이로 9가지 오답 패턴 분석 시스템을 통해 학생 본인 약점을 진단함과 동시에, 실제 수업 방식·소통 방식·과제 운영 방식을 미리 경험하시는 단계입니다.

**3단계 — 지도 계획 수립**
진단 결과 기반 3·6·12개월 단위 학습 path 계획 수립. 입시 컨설팅 영역 포함 시 자체 분석 시스템으로 수시 3안 + 정시 백업안 사전 산출.

**4단계 — 본 수업 시작 + 4주 후 1차 점검**
첫 4주는 학습 리듬 안착에 집중. 4주 시점에 학부모께 1차 보고 후 한 달 단위 정기 보고로 이행합니다.

### Q2. 어떤 서비스를 전문적으로 제공하나요? (약 490자)

본 강사는 11년 동안 입시 영역 전체를 통합 지도해 온 경력을 기반으로 6개 영역을 전문 제공합니다.

**국어** (대표 영역): 독서·문학·언매·화작·논술. 자체 9가지 오답 패턴 자동 분류 시스템 + 선지마다 지문 근거를 형광펜으로 1:1 매핑하는 풀이법 + 수능 5개년 204문항 자체 분석 DB.

**영어**: 어휘 (단어장 노하우) + 문법 (내신/수능 분리) + 구조 독해.

**수학**: 공통 (수1·수2) + 선택 (미적분·확통·기하). 학생 진로·희망학과 분석 후 선택과목 추천.

**입시 컨설팅** (수시·정시 통합): 수시 3안 (안전/균형/도전) 자체 분석 시스템 자동 산출 + 정시 백업안 + 자기소개서·면접·세특 관리 + 학부모 1페이지 요약 자동 생성.

**검정고시**: 전 과목 종합 관리.

**논술**: 인문·약술형 + 자기소개서 첨삭.

[차별점] 한 명의 강사가 입시 전 과정을 통합 지도하므로 강사 사이 소통 비용 없음. 자체 분석 시스템·DB로 단순 강의가 아닌 진단 기반 지도 제공.

### Q3. 서비스의 견적은 어떤 방식으로 산정되나요? (약 470자)

견적은 학생 학년·과목·횟수·옵션·지도 방식에 따라 차등 산정합니다.

**학년 기준**
- 중등: 회당 90분 기준 시간당 약 4만원
- 고등·N수: 시간당 약 5만원
- 자기소개서·논술·면접·수시/정시 컨설팅: 별도 협의

**기본 패키지 예시** (주 2회·회당 90분)
- 중등 월 약 48만원
- 고등 월 약 60만원

**옵션**
- 입시 컨설팅 추가 (월 정액 별도)
- 자기소개서 첨삭 (건당 별도)
- 자체 분석 시스템 학부모 리포트 (옵션)
- 수업 외 카톡 질의응답 (기본 포함)

**그룹 옵션**
2~3명 그룹 가능 — 인원 수 따른 할인 (2명 약 20% / 3명 약 30%).

**견적 절차**
1차 상담 (무료) → 학생 정보 수렴 → 견적 안내 → 시범과외 → 최종 결정.

본 강사는 1:1 협상으로 단가를 변경하지 않습니다. 모든 학생에게 동일 가격 기준 적용. 다과목 통합·다회차 시 자연스러운 패키지 할인이 적용됩니다.

### Q4. 완료한 서비스 중 대표적인 서비스는 무엇인가요? 소요 시간은 얼마나 소요 되었나요? (약 490자)

11년 동안 50명 이상의 학생을 지도하면서 영역별 대표 4건을 소개드립니다.

**1) 국어 1등급 안착 (총 8개월)**
고2 인문 여학생 / 3등급 → 안정 1등급 (98점). 주 2회·회당 90분·총 약 65회. 9가지 오답 패턴 분류로 본인 약점 (팩트 왜곡·인과 전도) 집중 보완.

**2) 인서울 경영학과 합격 (총 12개월)**
고3 인문 남학생 / 내신 5등급. 국·영·수 통합 + 수시 컨설팅 + 자기소개서. 주 3회·회당 120분·총 약 140회. 자체 컨설팅 시스템 3안 산출 → 균형안 합격.

**3) 자사고 진학 + 고등 연계 (3년+ 진행 중)**
중3 여학생 (현재 고1). 중등 국·영·수 + 자사고 자기소개서·면접 + 고등 연계. 주 2~3회·회당 90분. 자사고 합격 후 현재까지 연속 지도.

**4) 검정고시 + 진학 path (총 6개월)**
학교 밖 청소년 / 은평구 봉사 활동 중 만남. 주 1회·회당 120분. 검정고시 합격 후 진학 path 안내 진행 중.

본 4건 모두 학생 본인의 노력이 가장 큰 요인입니다. 본 강사는 가장 효율적인 path와 도구 (자체 분석 DB·컨설팅 시스템)를 제공한 역할을 수행했습니다.

### Q5. A/S 또는 환불 규정은 어떻게 되나요? (약 490자)

수업료는 기본적으로 수업 회차로 채워드리는 것을 원칙으로 합니다.

**환불 정책 (4단계)**
1. 결제 직후 ~ 첫 수업 전: 전액 환불
2. 첫 수업 후 ~ 30% 진행 전: 진행 회차 + 10% 차감 환불
3. 30~50% 진행: 진행 회차 + 30% 차감 환불
4. 50% 이상 진행: 잔여 회차 보강 또는 50% 환불

**A/S 영역**
- 수업 외 카톡 질의응답: 기본 포함 (평균 1~3시간 안 응답)
